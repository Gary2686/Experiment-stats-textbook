§1

在海底背單字：Godden & Baddeley (1980)

這是心理學最有名的實驗之一。研究者找來深海潛水員，請他們背 50 個單字的列表，十分鐘後回想。關鍵在於：

📍

因子 𝒜：學習的地點（A = 2）

a₁ 在沙灘上　／　a₂ 在海底

🎯

因子 ℬ：測驗的地點（B = 2）

b₁ 在沙灘上　／　b₂ 在海底

交叉後有 4 個條件：沙灘學→沙灘測、沙灘學→海底測、海底學→沙灘測、海底學→海底測。

關鍵設計決定：每位潛水員都跑過全部四個條件 → 𝒮 與 𝒜、ℬ 都交叉 → 設計寫成 𝒮 × 𝒜 × ℬ。
本章用 S = 5 位受試者的虛構複製版（原始研究有 16 位）。

🔮 作者的預測：一個 X 形的交互作用

理論主張：當編碼情境與提取情境「一致」時，記憶表現最好。

注意這個預測的形狀有多特別：
・沙灘學 + 沙灘測 → 好
・海底學 + 海底測 → 好
・沙灘學 + 海底測 → 差
・海底學 + 沙灘測 → 差

🎯 這個預測沒有任何主效果！「在哪裡學」平均起來沒差、「在哪裡測」平均起來也沒差。
作者預測全部的實驗效果都應該落在交互作用上——這是一個極其精準、因此也極難僥倖命中的預測。

🔮 理論預測的形狀（X 形交互作用）
§2

七個變異來源：複雜度跳躍

有三個因子（𝒜、ℬ、𝒮）全部互相交叉，所以變異來源包括：3 個主效果 + 3 個二階交互作用 + 1 個三階交互作用。

🌳 從 𝒮 × 𝒜 的 3 個來源，到 𝒮 × 𝒜 × ℬ 的 7 個來源
來源自由度理解公式
𝒜A − 1BS·Σ(Ma·· − M···)²
ℬB − 1AS·Σ(M·b· − M···)²
𝒮S − 1AB·Σ(M··s − M···)²
𝒜ℬ(A−1)(B−1)S·ΣΣ(Mab· − Ma·· − M·b· + M···)²
𝒜𝒮(A−1)(S−1)B·ΣΣ(Ma·s − Ma·· − M··s + M···)²
ℬ𝒮(B−1)(S−1)A·ΣΣ(M·bs − M·b· − M··s + M···)²
𝒜ℬ𝒮(A−1)(B−1)(S−1)ΣΣΣ(Yabs − Mab· − Ma·s − M·bs + Ma·· + M·b· + M··s − M···)²
總和ABS − 1ΣΣΣ(Yabs − M···)²
🔍 注意 𝒜ℬ𝒮 那一串的形狀（三階交互作用）：
Y − (三個兩兩平均) + (三個單一平均) − 總平均

減三個、加三個、再減一個——這是「容斥原理」的完美展現。
二階交互作用是「減二加一」，三階就是「減三加三減一」。看懂這個規律，第二十一、二十二章就不難了。
🤔 為什麼來源一下子變這麼多？
因為 𝒮 與兩個因子都交叉了。在 𝒮 × 𝒜 中，𝒮 只能跟 𝒜 產生一個交互作用（𝒜𝒮）。

但在 𝒮 × 𝒜 × ℬ 中，𝒮 可以跟 𝒜 交互、跟 ℬ 交互、還能跟 𝒜ℬ 一起交互 → 多出 𝒜𝒮、ℬ𝒮、𝒜ℬ𝒮 三個。

直觀的意義：
・𝒜𝒮 = 「不同的人對學習地點的反應不一樣」
・ℬ𝒮 = 「不同的人對測驗地點的反應不一樣」
・𝒜ℬ𝒮 = 「不同的人的交互作用形狀不一樣」

而這三個，正好就是 §4 要用來當誤差項的東西。
§3

分數模型：九個零件

𝒮 × 𝒜 × ℬ 的分數模型（Model I：𝒜、ℬ 皆固定）
Yabs = μ··· + αa + βb + ss + αβab + αsas + βsbs + αβsabs + eabs
比第十八章多了兩個交互作用項：βsbs（ℬ 與受試者）與 αβsabs（三者一起）。

αβs 叫做「二階交互作用」（second-order interaction）——因為 𝒜 × ℬ × 𝒮 裡面有兩個叉號。

⚠️ 跟第十八章同樣的混淆再度出現：最後兩項 αβsabs 與 eabs 的下標完全相同 → 它們永遠一起變動、無法分離。
通則：在完全重複量數設計中，誤差永遠與「最高階的交互作用」混淆。
🎲 別忘了 𝒮 永遠是隨機因子（公式中用正體 s 而非希臘字母就是在提示這件事）。
這個事實是下一節所有 F 分母的根源——正因為 𝒮 是隨機的，它與固定因子的交互作用才會帶著隨機變異跑進主效果的期望均方裡。
§4

期望均方決定一切：三個效果、三個不同的分母

第十六章學過「比對 EMS 找分母」。本章是這個技巧最關鍵的應用場合——因為三個效果的分母全都不一樣。

🔬 期望均方表（Model I）：點任一列，看該效果該用哪個分母、為什麼
𝒜 的主效果
FA = MSA / MSAS
ν₁ = A−1, ν₂ = (A−1)(S−1)
ℬ 的主效果
FB = MSB / MSBS
ν₁ = B−1, ν₂ = (B−1)(S−1)
𝒜ℬ 交互作用
FAB = MSAB / MSABS
ν₁ = (A−1)(B−1), ν₂ = (A−1)(B−1)(S−1)
🔑 一眼看懂的規律

每個效果的分母，就是「它自己 × 𝒮」的那個交互作用。

・檢定 𝒜　→　分母 𝒜𝒮
・檢定 ℬ　→　分母 ℬ𝒮
・檢定 𝒜ℬ　→　分母 𝒜ℬ𝒮

直觀的意義：要判斷「𝒜 的效果是真的嗎」，要拿它跟「𝒜 的效果在人與人之間波動多大」比較。如果效果遠大於它的波動，才算穩定存在。

這其實就是第十八章 𝒮 × 𝒜 的邏輯（FA = MSA/MSAS）原封不動地推廣。

🚫 有四個來源「無法被檢定」：𝒮、𝒜𝒮、ℬ𝒮、𝒜ℬ𝒮。
因為找不到任何一個均方，在 H₀ 為真時與它們有相同的期望值。

但這不影響我們：實驗真正關心的 𝒜、ℬ、𝒜ℬ 三者都檢定得了。
📌 課本的重要註記：當 𝒜、ℬ 都是固定因子時，𝒮 × 𝒜 × ℬ 與 𝒮(𝒜 × ℬ) 能檢定的統計假設完全相同——差別只在用了多少人、以及誤差有多小。

§8

如果 𝒜、ℬ 是隨機因子：主效果變得無法檢定

🚨 課本在這裡給了一個嚴厲的提醒：
「在 𝒮 × 𝒜 × ℬ 設計中，把因子視為固定或隨機，其後果比 𝒮(𝒜 × ℬ) 設計嚴重得多。」

嚴重到什麼程度？主效果可能完全檢定不了。
🎲 三種模型下，哪些來源檢定得了？（點按鈕切換）
🤔 Model II 為什麼 𝒜 檢定不了？看 EMS 就懂
當 𝒜、ℬ 都隨機時：
E{MSA} = σ²e + σ²abs + B·σ²as + S·σ²ab + BS·σ²a

H₀ 為真時（σ²a = 0），剩下 σ²e + σ²abs + B·σ²as + S·σ²ab。

現在找找看有沒有哪個均方剛好等於這一串：
・MSAB = σ²e + σ²abs + S·σ²ab → 少了 B·σ²as ✗
・MSAS = σ²e + σ²abs + B·σ²as → 少了 S·σ²ab ✗
・MSABS = σ²e + σ²abs → 少了兩項 ✗

沒有任何一個對得上。所以 𝒜 的主效果無法用標準的 F 檢定。

但觀察一下：MSAB + MSAS − MSABS 會等於什麼？
= (σ²e + σ²abs + S·σ²ab) + (σ²e + σ²abs + B·σ²as) − (σ²e + σ²abs)
= σ²e + σ²abs + B·σ²as + S·σ²ab → 剛好對上了！

這個「組合出來的分母」就是 §9 的 Quasi-F。
§9

Quasi-F：自己組一個分母出來

當找不到現成的分母時，統計學家的解法很直接：把幾個均方加加減減，湊出一個期望值剛好對的量。

Quasi-F（F′，讀作 F prime）
MS′test,A = MSAB + MSAS − MSABS　　F′A = MSA ／ MS′test,A
Satterthwaite (1946) 證明：F′ 近似服從 Fisher 分配，ν₁ = A − 1，而 ν₂ 要用下面這條相當嚇人的公式算：
ν₂ 的近似公式
ν₂ ≈ (MSAB + MSAS − MSABS)² ／ [ (MS²AB/dfAB) + (MS²AS/dfAS) + (MS²ABS/dfABS) ]
⚠️ 課本特別標註的陷阱：分子裡的均方有加有減（照原本的組合），但分母裡的項永遠都是「加」。

算出來通常不是整數 → 用臨界值法時四捨五入到最近的整數；若用電腦算精確機率，直接帶小數會更精準。
🧮 Quasi-F 計算器：如果 Godden & Baddeley 的 𝒜、ℬ 是隨機因子呢？
😮 結論完全翻盤

把 𝒜 當成固定因子：FA = 80 / 40 = 2.00
把 𝒜 當成隨機因子：F′A = 80 / 344 = 0.233

分母從 40 暴增到 344（因為把三個誤差來源加總起來了），F 掉到不到四分之一。
而且 ν₂ 只剩 1（1.15 四捨五入），臨界值高到幾乎不可能達到。

🎯 方法論的教訓：「這個因子是固定還是隨機」不是一個可以隨便回答的問題。
它會改變分母、改變自由度、改變結論。這個決定必須在設計實驗時就想清楚（回頭看第十章 §7 的判準：「別人複製時會用一模一樣的水準嗎？」）。

🔧 備案：F″（F second）

注意 MS′ = MSAB + MSAS − MSABS 這個式子裡有個減號——所以它可能算出負數（變異數估計值為負，沒有意義）。

這時改用另一種 Quasi-F，把減號換成「兩邊都加」的形式：

F″ 的公式（避免負分母）
F″A = (MSABS + MSA) ／ (MSAB + MSAS)
為什麼這樣也對？比對兩邊的期望值：
分子 E = (σ²e + σ²abs) + (σ²e + σ²abs + Bσ²as + Sσ²ab + BSσ²a)
分母 E = (σ²e + σ²abs + Sσ²ab) + (σ²e + σ²abs + Bσ²as)
H₀ 為真時（σ²a = 0）兩邊完全相同 ✓ → F″ ≈ 1

兩個自由度都要用 Satterthwaite 公式分別近似：
ν₁ ≈ (MSABS + MSA)² / [(MS²ABS/dfABS) + (MS²A/dfA)]
ν₂ ≈ 同理，用分母的兩個均方
📌 課本的收尾：「同樣的程序可以用在所有的因子設計上，無論多複雜。」
這正是第二十二章要系統化的事——給你一套規則，讓你能處理任何設計的期望均方與 F 分母。
