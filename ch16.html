§1

開場：為什麼 Treisman 必須用兩個因子

先玩個遊戲。下面兩組圖，請找出跟別人不一樣的那個字母：

👁️ Treisman (1986) 的視覺搜尋作業（重繪）
🔍 你的主觀感受是什麼？
左邊的 Q 藏在一堆 O 之中——不管旁邊有幾個 O，Q 都會「跳出來」（pop-out）。
右邊的 T 藏在一堆 L 之中——因為 T 跟 L 共用了「一橫一豎」這些特徵，你得一個一個檢查，旁邊的 L 越多就越慢。
🎯 Treisman 的理論要求兩個因子

Treisman 的注意力理論主張：

・當目標與干擾物不共用特徵時 → 平行處理（一眼看完）→ 干擾物數量不影響反應時間
・當目標與干擾物共用特徵時 → 序列搜尋（逐個檢查）→ 干擾物越多越慢

注意這個預測的形狀：「干擾物數量的效果，取決於有沒有共用特徵」。
這就是一個交互作用的預測——必須同時操弄兩個因子才檢驗得了。

這一章要學的設計寫作 𝒮(𝒜 × ℬ)，或簡寫成 𝒜 × ℬ。意思是：兩個自變數完全交叉，而每位受試者只被分派到其中一個條件組合（所以 𝒮 巢套在整個設計之下）。

🎁 好消息 & 壞消息
好消息：第七～十四章的所有工具（平方和、自由度、均方、F 比值、效果量）全部照用，一個都不用丟。
壞消息：只有一個全新概念要學——交互作用。但它重要到值得整章的篇幅。

⚖️ 另外提醒：在多因子設計中，平衡設計（各組人數相同）比單因子時更重要。因為只有平衡時，實驗平方和才能被乾淨地「切成三塊」（§7 會看到原因）。而且分派必須是隨機的，結論才能推論。
§2

設計的組織：從「幾個水準」到「幾個格子」

單因子設計中，一個實驗條件＝自變數的一個水準。二因子設計中，一個實驗條件＝兩個自變數水準的特定組合。

如果 𝒜 有 4 個水準、ℬ 有 3 個水準，交叉後就有 4 × 3 = 12 個實驗組（集合論裡這叫「卡氏積」）。這種設計就叫 4 × 3 設計（讀作「4 by 3」）。

本章的主角實例是 Tulving & Pearlstone (1966) 記憶實驗的複製版：

📏

因子 𝒜：列表長度（A = 3）

受試者要背的單字數量：12 字 / 24 字 / 48 字。

這些字可以兩兩歸成類別（蘋果、橘子 → 水果）。學習時螢幕會顯示類別名稱，但告訴受試者不必記類別名。

🔑

因子 ℬ：回想時有無線索（B = 2）

學完後馬上測驗。一半的人拿到類別名稱清單（cued recall，線索回憶），另一半沒有（free recall，自由回憶）。

依變數：正確回想的單字數。

　a₁：12 字a₂：24 字a₃：48 字
b₁：自由回憶a₁b₁a₂b₁a₃b₁
b₂：線索回憶a₁b₂a₂b₂a₃b₂

3 × 2 設計 → 6 個實驗組，每組 10 人 → 總共 60 位受試者

🔎 另一種看法：二因子＝好幾個單因子疊在一起

你可以把這個實驗看成兩個單因子實驗：

・次設計 1（自由回憶組）：單因子三水準——12、24、48 字
・次設計 2（線索回憶組）：單因子三水準——12、24、48 字

每一個這樣的次設計，它的實驗效果就叫做單純效果（simple effect）。
（當然，反過來看成三個「2 水準設計」也可以。）

🔑 記住「單純效果」這個詞——§5 會用它來給交互作用下定義。

§3

記號：從兩個下標變成三個

第七章的記號直接推廣。唯一的改變是：指認一個分數現在需要三個下標（哪個 A 水準、哪個 B 水準、第幾位受試者）。

Mab·該格的平均 = Yab· / SM₃₂· = 29
Ma··𝒜 第 a 水準的邊際平均（把 b 和 s 都加總掉）M₃·· = 24
M·b·ℬ 第 b 水準的邊際平均M·₂· = 18

🔤 「點」還是同一個規則（第七章學過）：下標裡的點代表「這個下標已經被加總掉了」。
・Ma··：固定 a，把 b 和 s 都平均掉 → 只剩 𝒜 的效果 → 所以叫「邊際平均」

📐 除數要小心：Ma·· = Ya·· ／ (B × S)，因為這個水準涵蓋了 B 格 × 每格 S 人。
§4

主效果：把另一個因子「平均掉」

先看一個沒有交互作用的虛構例子（課本 Table 16.1）。這是一個 3×3 設計，表格內是各格的平均數 Mab·：

因子 ℬ ＼ 因子 𝒜a₁a₂a₃ℬ 的邊際平均
b₁7.56.04.56.0
b₂7.05.54.05.5
b₃3.52.00.52.0
𝒜 的邊際平均6.04.53.04.5

邊際平均怎麼來的？就是把那一行（或那一列）平均起來。例如 ℬ 第 3 水準的邊際平均：
M·3· = (3.5 + 2.0 + 0.5) ／ 3 = 2.0

主效果的定義
𝒜 的主效果 = 那一排邊際平均：M₁·· = 6.0、M₂·· = 4.5、M₃·· = 3.0

ℬ 的主效果 = 那一欄邊際平均：M·₁· = 6.0、M·₂· = 5.5、M·₃· = 2.0
關鍵觀念：計算 𝒜 的主效果時，我們是跨越 ℬ 的所有水準去平均——
這等於是「先不管 ℬ 的存在」，純粹看 𝒜 整體造成的差異。

所以「主效果」= 把另一個因子平均掉之後，剩下的那個因子的效果。
§5

交互作用：本章的主角

算邊際平均（主效果）時，另一個因子被忽略了。而交互作用揭露的，正是兩個自變數的「共同作用」——這是多因子設計獨有的概念。

我們用兩張表來對照：它們的邊際平均完全相同，但格子內容不同。

⚖️ 對照：沒有交互作用 vs 有交互作用（兩者主效果一模一樣！）
📏 沒有交互作用時：線是平行的

在 Table 16.1 中，不管 ℬ 在哪個水準，a₁ 永遠比 a₂ 高 1.5、比 a₃ 高 3.0。
所以三條線完全平行——這就是「沒有交互作用」的視覺特徵。

更厲害的性質：可加性（additivity）
沒有交互作用時，你可以只用邊際平均和總平均，把每一格的值算回來：

Ma₁b₁ = 總平均 + 𝒜 的效果 + ℬ 的效果
7.5 = 4.5 + (6.0 − 4.5) + (6.0 − 4.5) = 4.5 + 1.5 + 1.5 ✓

試試看把整張表重建出來——這是課本留的練習。

現在看 Table 16.2。邊際平均完全沒變（6.0/4.5/3.0 與 6.0/5.5/2.0），但格子內容變了：

因子 ℬ ＼ 因子 𝒜a₁a₂a₃邊際
b₁6.06.06.06.0
b₂8.07.51.05.5
b₃4.00.02.02.0
邊際6.04.53.04.5
🚨 看出差別了嗎？在 b₁ 這一列，𝒜 完全沒有效果（6.0, 6.0, 6.0）；在 b₂ 這一列，a₃ 整個崩盤（1.0）；在 b₃ 這一列，a₂ 最低。

𝒜 的效果，完全取決於你在 ℬ 的哪個水準。線不再平行了。

致命的後果：主效果說「a₁ > a₂ > a₃」（6.0 > 4.5 > 3.0）——但這句話對任何一個實際的條件都不成立！它只是三條互相矛盾的曲線被平均出來的幻影。

🔑 交互作用的四種等價定義

課本一口氣給了四個定義。它們講的是同一件事，但從四個角度切入——全部都要會，因為不同場合用不同說法最順：

1
幾何定義：當 𝒜 與 ℬ 有交互作用時，各個單純效果彼此不同，描繪它們的線不平行。
2
條件定義：一個自變數的效果，取決於另一個自變數的水準。
3
資訊定義：主效果不足以完整說明該自變數的效果——你非得同時交代另一個因子不可。
4
代數定義：無法用邊際平均和總平均推算出各格的平均（可加性失效）。
🤔 想一想：有交互作用時，還能報告主效果嗎？
能報告，但必須非常小心地詮釋。

以 Table 16.2 為例，𝒜 的主效果是 6.0 / 4.5 / 3.0，看起來「a₁ 最好」。但實際上：b₁ 時三者相同、b₂ 時 a₃ 慘敗、b₃ 時 a₂ 最差。主效果描述的是一個不存在於任何真實條件下的「平均情境」。

實務準則：
① 交互作用顯著時，優先詮釋交互作用，主效果降為次要；
② 通常要接著做單純效果分析（在 ℬ 的每個水準下分別檢定 𝒜）——這是第十七章的內容；
③ 報告時務必附上圖，讓讀者自己看見線的形狀。

📐 怎麼用「一個數字」判斷有沒有交互作用？（2×2 的情形）
交互作用量 = (Ma₁b₁ − Ma₂b₁) − (Ma₁b₂ − Ma₂b₂)

翻譯：「在 b₁ 下 𝒜 造成的差距」減去「在 b₂ 下 𝒜 造成的差距」。
兩個差距一樣大 → 相減 = 0 → 沒有交互作用（線平行）。
差距不同 → 不等於 0 → 有交互作用。

試試上面的預設 ①：(4−8) − (10−14) = (−4) − (−4) = 0 → 平行 ✓
預設 ②：(4−12) − (12−4) = (−8) − (8) = −16 → 強烈交互作用 ✓

📈

次序型交互作用
ordinal interaction

線不平行，但不相交（或在資料範圍外才相交）。效果的大小改變，但方向沒變。

→ 試試預設 ③

❌

非次序型交互作用
disordinal interaction

線交叉了。效果的方向在不同條件下反轉——「對 A 組有益的，對 B 組有害」。

→ 試試預設 ④。這種結果理論上最有價值，也最難詮釋。

§7

平方和：從兩分變成四分

第七章把總平方和切成兩塊（組間、組內）。現在策略完全一樣，只是組間那塊要再切成三份。

✂️ 兩階段切割：先切出誤差，再把實驗效果切成三份
第一步：跟第七章一模一樣
Yabs − M···　=　(Yabs − Mab·)　+　(Mab· − M···)
　　　　總偏差　　　　　＝　　組內偏差（誤差）　＋　　組間偏差（實驗效果）

注意「組」現在指的是「一格」（一個 ab 組合），共 A×B 格。
第二步：把組間偏差再拆成三份（本章的新東西）
(Mab· − M···) = (Ma·· − M···) + (M·b· − M···) + (Mab· − Ma·· − M·b· + M···)
　　　組間偏差　　　＝　𝒜 的主效果　＋　ℬ 的主效果　＋　𝒜ℬ 交互作用

怎麼驗證？把右邊的括號拆掉，所有 Ma··、M·b·、M··· 兩兩對消，只剩下 Mab· − M··· ✓
🧠 交互作用項的真正意義：「扣掉主效果後剩下的東西」

把上面的式子移項，交互作用就變得非常好懂：

(Mab· − Ma·· − M·b· + M···)
=　(Mab· − M···)　−　(Ma·· − M···)　−　(M·b· − M···)
交互作用　＝　這一格實際偏離多少　−　𝒜 能解釋的　−　ℬ 能解釋的

所以交互作用是一個「殘差」概念：把兩個主效果都扣掉之後，這一格還剩下多少無法解釋的偏離。剩得越多，交互作用越強。

這也解釋了為什麼「可加性失效」＝「有交互作用」：可加時主效果剛好把一切解釋完，殘差為 0。

把偏差平方、加總，就得到三個平方和。注意前面的乘數：

𝒜 的主效果
SSA = B·S·Σ(Ma·· − M···)²
乘 B×S：每個 A 水準底下有 B 格、每格 S 人
ℬ 的主效果
SSB = A·S·Σ(M·b· − M···)²
乘 A×S：同理
交互作用
SSAB = S·ΣΣ(Mab· − Ma·· − M·b· + M···)²
只乘 S：因為每一格只有 S 人
誤差
SSS(AB) = ΣΣΣ(Yabs − Mab·)²
每個人離自己那一格的平均多遠
完整的平方和分割
SStotal = SSA + SSB + SSAB + SSS(AB)
為什麼可以乾淨相加？把三項式平方展開會得到三個平方項加三個交叉項（就像 (a+b+c)²）。
課本說：當設計平衡時，所有交叉項都會消失——跟第七章證明交叉項 = 0 的技巧完全相同。

⚠️ 這就是 §1 強調「平衡設計在多因子中更重要」的原因：不平衡時交叉項不為零，平方和就無法乾淨切割，必須改用迴歸途徑處理。
🔬 畫出「純交互作用」：把主效果扣掉之後的樣子
👁️ 左圖是原始的格平均 Mab·，裡面混合了三種效果。右圖只畫交互作用項 (Mab· − Ma·· − M·b· + M···)。

§8

自由度、均方與三個 F

來源自由度為什麼
𝒜A − 1A 個邊際平均，但總平均是它們的平均 → 花掉 1 個
ℬB − 1同理
𝒜ℬ(A − 1)(B − 1)見下方說明 👇
𝒮(𝒜ℬ)AB(S − 1)共 A×B 格，每格 S 人、估一個格平均 → 每格剩 S−1
總和ABS − 1總共 ABS 個觀察值，估總平均花掉 1 個
🤔 為什麼交互作用的自由度是 (A−1)(B−1)？
關鍵在於：邊際平均可以從格平均算出來，這對格平均造成了約束。

・在任何一欄（固定 a）：B 個格平均必須平均成該欄的邊際平均 → 只有 B − 1 個能自由變動
・在任何一列（固定 b）：同理只有 A − 1 個能自由變動

把這個原則擴展到整張表，交互作用的自由度就是 (A − 1)(B − 1)。

直觀檢查：在 3×2 表中 = 2 × 1 = 2。也就是說，你只要知道 2 個交互作用項，其餘 4 個就被約束決定了。

💡 更好記的方法（第十六章後面會正式教）：把來源名稱裡括號外的字母減 1、括號內的保持原值，相乘即得。AB → (A−1)(B−1)；S(AB) → AB(S−1)。
檢查：自由度加起來要等於總自由度
(A−1) + (B−1) + (A−1)(B−1) + AB(S−1) = ABS − 1
本章實例（A=3, B=2, S=10）：2 + 1 + 2 + 54 = 59 = 3×2×10 − 1 ✓
算完一定要做這個檢查，很容易抓到錯誤。

每個平方和除以自己的自由度得到均方，然後——這裡是重點——三個效果都用同一個分母：MSS(AB)（當兩個因子都是固定因子時）。

𝒜 的主效果
FA = MSA / MSS(AB)
ν₁ = A−1, ν₂ = AB(S−1)
ℬ 的主效果
FB = MSB / MSS(AB)
ν₁ = B−1, ν₂ = AB(S−1)
交互作用
FAB = MSAB / MSS(AB)
ν₁ = (A−1)(B−1), ν₂ = AB(S−1)
🎯 邏輯跟單因子完全一樣：H₀ 為真時，分子與分母都只是在估計誤差變異 σ²e，所以 F 會在 1 附近。
§9 的分數模型會用期望均方嚴格證明這件事，並且揭露一個重要的但書——這個「三個都除以 MSS(AB)」的做法，只在兩個因子都是固定因子時才對（§11）。
§9

分數模型：一個分數現在有五個零件

第十章學過：單因子時，一個分數 = 總平均 + 處理效果 + 誤差。二因子時中間多了兩塊。

二因子分數模型（Model I：兩因子皆固定）
Yabs = μ··· + αa + βb + αβab + es(ab)
μ···　母體總平均
估計值：M···
αa　𝒜 第 a 水準的效果
估計值：Ma·· − M···
βb　ℬ 第 b 水準的效果
估計值：M·b· − M···
αβab　交互作用效果
估計值：Mab· − Ma·· − M·b· + M···
es(ab)　誤差
估計值：Yabs − Mab·
🔒 模型的約束條件（固定因子時）
① Σαa = 0　② Σβb = 0
③ 交互作用項「橫著加、豎著加」都要等於 0：Σa αβab = Σb αβab = 0
④ 誤差：es(ab) ~ N(0, σ²e)，期望值為 0、變異數與實驗組無關、服從常態

第 ③ 條正是 §8 那個 (A−1)(B−1) 自由度的來源——每一行、每一列都被綁住一個。
🧩 分數組裝器：點任一格，看它的平均如何由五個零件堆出來

把分數模型代進平方和的定義，就得到期望均方（EMS）——它告訴我們每個均方「長期來看在估計什麼」：

期望均方（Model I：𝒜、ℬ 皆為固定因子）
E{MSA} = σ²e + B·S·θ²a
E{MSB} = σ²e + A·S·θ²b
E{MSAB} = σ²e + S·θ²ab
E{MSS(AB)} = σ²e
其中 θ²a = Σα²a/(A−1)、θ²b = Σβ²b/(B−1)、θ²ab = Σαβ²ab/[(A−1)(B−1)]

怎麼讀這張表：每個均方 = 「誤差」＋「自己的效果」。
檢定某個效果時，找一個「除了那個效果項以外，其他都一樣」的均方當分母。
這裡三個效果的分母都是 MSS(AB)（因為它只有 σ²e）—— H₀ 為真時該效果項 = 0，分子分母期望值相同，F ≈ 1 ✓

📌 這個「比對 EMS 找分母」的方法，是第十九～二十二章的核心技能。先在這裡把它看熟。

🤔 作者真正想要的是哪一個效果？
課本特別點出：列表長度的主效果其實很「無聊」——背的字越多，能回想的當然越多，這不需要做實驗就知道。

作者真正感興趣的是交互作用：提取線索的幫助有多大，會不會取決於列表長度？

答案是會：短列表（12 字）時，有沒有線索完全沒差（10 vs 10）；長列表（48 字）時，線索讓成績從 19 衝到 29。

這就是「多因子設計是更好的理論檢驗」的具體例子——作者的理論預測的不是主效果，而是交互作用的形狀。

逐步計算

Step 1 · SSA（列表長度的主效果）
SSA = B·S·Σ(Ma·· − M···)² = 2 × 10 × [(10−16)² + (14−16)² + (24−16)²]
= 20 × [36 + 4 + 64] = 20 × 104 = 2,080.00
Step 2 · SSB（提取線索的主效果）
SSB = A·S·Σ(M·b· − M···)² = 3 × 10 × [(14−16)² + (18−16)²]
= 30 × [4 + 4] = 30 × 8 = 240.00
Step 3 · SSAB（交互作用）

六個交互作用項（每格算一次）：

a₂b₁：13 − 14 − 14 + 16 = +1　｜　a₂b₂：15 − 14 − 18 + 16 = −1

= 10 × [4 + 4 + 1 + 1 + 9 + 9] = 10 × 28 = 280.00

Step 4 · SSS(AB)（誤差）
SSS(AB) = ΣΣΣ(Yabs − Mab·)²
每個人減掉自己那一格的平均再平方，全部加總：

💡 課本最後那句話，值得抄在筆記本上

「這個交互作用主要源自於：線索的促進效果只在長列表（48 字）時才顯現。因此，一個用短列表來展示『線索效果』的實驗，很可能會報告出虛無的結果。」

這句話的方法論意義極深：當存在交互作用時，你選擇的「另一個因子的水準」會決定你看不看得到效果。
很多文獻中的「複製失敗」，真正的原因就是兩個研究用了不同的背景條件——而交互作用正是解釋這類矛盾的鑰匙。

§11

當因子是隨機的：F 的分母會換人

🚨 本章最容易出錯、也最少人注意的一節。
前面所有 F 都是「除以 MSS(AB)」——那只在兩個因子都是固定因子（Model I）時才正確。

第十章學過固定因子與隨機因子的分別。二因子設計多了一種可能：一個固定、一個隨機。於是有三種模型：

🎲 三種模型的 F 分母對照（點按鈕切換）
🔑 為什麼分母會換？看期望均方就懂了

以 Model II（兩個都隨機）為例，EMS 變成：

E{MSA} = σ²e + S·σ²ab + BS·σ²a
E{MSB} = σ²e + S·σ²ab + AS·σ²b
E{MSAB} = σ²e + S·σ²ab
E{MSS(AB)} = σ²e

想檢定 𝒜（H₀：σ²a = 0），要找一個分母——它必須跟分子「除了 BS·σ²a 以外完全一樣」。

・用 MSS(AB)？它只有 σ²e，少了 S·σ²ab → 就算 H₀ 為真，F 也不會是 1 → 錯！
・用 MSAB？它是 σ²e + S·σ²ab，剛好對上 → H₀ 為真時兩者期望值相同 → 正確！

🎯 這就是「比對期望均方來挑分母」的核心技巧。第二十二章會把它變成一套通用規則，讓你能處理任何設計。

⚠️ 課本特別標註的陷阱（Model III）
當 𝒜 固定、ℬ 隨機時，很多人的直覺是「固定因子 𝒜 應該除以 MSS(AB)」。
錯。正確的是 FA = MSA / MSAB，而隨機因子 ℬ 反而用 MSS(AB)。

為什麼反直覺卻正確？因為固定因子 𝒜 的 EMS 裡含有交互作用項（它與隨機因子交互時會帶進隨機變異），而隨機因子 ℬ 的 EMS 裡沒有。看 EMS，不要靠直覺。

Model II 的實例：投射測驗研究

① 均方的算法完全沒變——SS、df、MS 跟 Model I 一模一樣。只有 F 的分母換了。

§12

效果量：三種問法，三種 R²

二因子設計的效果量比單因子複雜，因為可以問三種不同的問題。課本用一個 3×2、每格 3 人的小範例（N = 18）來示範，它的數字特別乾淨：

　a₁a₂a₃邊際
b₁1513511
b₂9999
邊際1211710

SSA = 84　SSB = 18　SSAB = 84　SSS(AB) = 54　SStotal = 240

① 全域指標（global）：「佔總變異的幾成？」

用總平方和當分母
R²Y·source = SSsource ／ SStotal
R²Y·A = 84/240 = .350　｜　R²Y·B = 18/240 = .075
R²Y·AB = 84/240 = .350　｜　R²Y·S(AB) = 54/240 = .225

✨ 四個加起來 = .350 + .075 + .350 + .225 = 1.000
為什麼必然如此？因為 SSA + SSB + SSAB + SSS(AB) = SStotal。整塊蛋糕被四個來源分完。
🥧 變異的四等分（全域 R²）

② 偏指標（partial）：「跟誤差比，這個效果多大？」

分母只含「自己 + 誤差」，把其他效果拿掉
R²Y·A/B,AB = SSA ／ (SSA + SSS(AB))
本例：84 / (84 + 54) = .609　（相較於全域的 .350 明顯更大）

意義：這是半偏相關的平方——「把 ℬ 與 𝒜ℬ 的效果排除（partial out）之後，𝒜 與分數的相關」。
更精確地說，它是 (Ma·· − M···) 與「Yabs 扣掉 ℬ 效果與交互作用效果之後的殘餘」兩者的相關平方。

📌 單因子設計時 𝒜 是唯一來源，所以全域與偏指標完全相同——差別只在多因子時才出現。
📌 這就是 SPSS 報表裡的 partial η²（偏 eta 平方），論文中最常被報告的那一個。
🤔 為什麼偏指標比全域指標大？該報哪一個？
為什麼比較大：分母從「全部變異」縮小成「自己＋誤差」，把其他效果佔走的那塊拿掉了，比例自然變大。

該報哪一個？取決於你的問題：
・想說「這個效果佔整個現象的多少」→ 用全域 R²（也是 η²）
・想跨研究比較效果大小 → 用偏 η²，因為它比較不受「同一個研究裡還有哪些其他因子」影響

⚠️ 常見錯誤：把偏 η² 當成全域 η² 解讀，說「這個因子解釋了 60.9% 的變異」——那是錯的，它只解釋了 35%。偏 η² 不會加起來等於 1，而且各個偏 η² 相加可能超過 1。報告時務必寫清楚用的是哪一種。

③ 分割實驗效果：「在三個效果之中，誰的貢獻最大？」

分母是「實驗效果總和」（不含誤差）
R²exp·source = SSsource ／ (SSA + SSB + SSAB)
本例實驗效果總和 = 84 + 18 + 84 = 186
𝒜：84/186 = .452　｜　ℬ：18/186 = .097　｜　𝒜ℬ：84/186 = .452

用途：當你想說「實驗操弄造成的全部效果中，有 45% 來自交互作用」時用這個。
它可以被理解為「該效果來源」與「各格平均數 Mab·」之間的相關平方（注意：對象是平均數，不是個別分數）。
F 與 R² 的關係（與第八章同一條式子）
Fsource = [R²Y·source ／ R²Y·S(AB)] × [dfS(AB) ／ dfsource]
驗證本例（dfS(AB) = 12）：
FA = (.350/.225) × (12/2) = 9.333　｜　FB = (.075/.225) × (12/1) = 4.000　｜　FAB = (.350/.225) × (12/2) = 9.333

用均方算：MSA = 84/2 = 42、MSS(AB) = 54/12 = 4.5 → F = 42/4.5 = 9.333 ✓
兩條路殊途同歸——再次印證「ANOVA 就是迴歸」（第九章）。
§13

手算捷徑：五個「方框數字」

第八章學過的「方框裡的數字」在這裡直接推廣。二因子需要五個方框：⟦1⟧ ⟦A⟧ ⟦B⟧ ⟦AB⟧ ⟦ABS⟧

建構規則完全相同：方框裡有的字母當活躍下標，沒有的用「·」代替；有活躍下標就加 Σ；有不活躍下標就除以對應的大寫字母。

量定義Tulving 實例的計算
Q1Y···（總和）11 + 7 + … + 28 = 960.00
Q2⟦ABS⟧ = ΣY²abs11² + 7² + … + 28² = 18,446.00

SSAB　=　⟦AB⟧ − ⟦A⟧ − ⟦B⟧ + ⟦1⟧

這不是巧合——計算公式本來就是從理解公式代數推導出來的。方框記號保留了理解公式的「形狀」，只是把「平均數」換成「平方和式的量」。
