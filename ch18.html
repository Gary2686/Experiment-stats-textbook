𝒮 × 𝒜

§1

同樣的實驗，少用三分之二的人

假設自變數有 3 個水準，每個水準要收 4 筆觀察值。兩種做法的受試者分派完全不同：

👥 同樣是「每格 4 筆資料」，兩種設計需要的人數差三倍
受試者間 𝒮(𝒜)　需要 12 人
重複量數 𝒮 × 𝒜　只要 4 人
🔤 記號上的微妙變化：Yas 在這裡的意思變了！
在 𝒮(𝒜) 中，s₁ 和 s₅ 是不同的兩個人；在 𝒮 × 𝒜 中，s 在所有水準間指的是同一個人。
這個小改變，是後面一切推導的起點。
🎯 但省錢只是附帶好處，真正的大禮是「檢定力」

回想 F 的結構：

F = MS效果 ／ MS誤差

誤差（分母）越小，F 越大，越容易拒絕 H₀。

重複量數設計之所以厲害，是因為它能把「個別差異」從誤差裡挖出來丟掉——而個別差異往往是心理學實驗中最大的噪音來源。

一句話：每位受試者都當自己的控制組。

🪆 換個角度：𝒮 × 𝒜 其實是一種二因子設計
把「受試者」當成第二個因子，這就是一個 𝒮 × 𝒜 的交叉設計（而且 𝒮 是隨機因子——我們假設這批人是母體的隨機樣本，結論要能推廣到整個母體）。

但有一個關鍵差異：在第十六章的 𝒜 × ℬ 中，每一格有 S 個分數；這裡每一格只有「一個」分數（一位受試者在一個條件下只測一次）。
後果：𝒮 × 𝒜 的交互作用與實驗誤差混淆在一起、無法分離。§7 會看到這件事的全部意涵。
§2

為什麼不能再用 SSS(A) 當誤差？

在 𝒮(𝒜) 設計中，SSS(A)（組內變異）是誤差的好估計——因為同組的人接受相同處理，他們的差異只能是誤差。

但在重複量數設計中，這個邏輯破了。課本用兩個極端的反例，一眼就讓你看出問題：

🔍 兩個「誤差明明是 0」的反例（點按鈕切換）
🚨 兩個反例的共同點：實驗誤差明明等於 0（每位受試者的反應完全規律、毫無隨機波動），但 SSS(A) 卻是個大數字。

原因很明顯：SSS(A) 裡面裝的全是「人跟人本來就不一樣」的個別差異——s₁ 天生分數高、s₂ 天生分數低。

在受試者間設計中，這些個別差異確實無從區分，只能算進誤差。
但在重複量數設計中，我們看得到同一個人在不同條件下的表現，所以可以把他的「個人水準」扣掉。
§3

關鍵一刀：SSS(A) = SSS + SSAS

既然組內變異裡混了「個別差異」與「真正的誤差」，那就把它再切一刀。

首先引進一個新記號：M·s = Y·s / A，讀作「第 s 位受試者的平均」——把他在所有條件下的分數平均起來，代表他的「個人水準」。

把組內偏差再拆成兩段
(Yas − Ma·)　=　(M·s − M··)　+　(Yas − Ma· − M·s + M··)
　　組內偏差　　＝　受試者間偏差（這個人整體偏高/偏低多少）　＋　殘差

殘差怎麼來的？用減的：殘差 = 組內偏差 − 受試者偏差。
把「這個人整體的高低」扣掉之後，還剩下的那部分偏離，才是真正的誤差。

👀 眼熟嗎？這個殘差的形狀 (Y − Ma· − M·s + M··) 跟第十六章的交互作用項一模一樣——它就是 𝒜 與 𝒮 的交互作用。
✂️ 兩階段切割：先分出實驗效果，再把「誤差」裡的個別差異挖出來
平方和的三分割
SSS(A) = SSS + SSAS

SStotal = SSA + SSS + SSAS
SSS = A · Σ(M·s − M··)²　受試者的個別差異（乘 A，因為每人跑了 A 個條件）
SSAS = ΣΣ(Yas − Ma· − M·s + M··)²　殘差 = 𝒜×𝒮 交互作用 = 新的誤差項

和第七章一樣，這個分割成立是因為交叉項 Σ(Y−Ma·−M·s+M··)(M·s−M··) = 0。課本把證明留作練習，技巧與第七章完全相同。
§4

新的 F 比值：分母換成 MSAS

𝒮 × 𝒜 設計的 F
FA = MSA ／ MSAS
跟 𝒮(𝒜) 唯一的差別：分母從 MSS(A) 換成 MSAS（扣掉個別差異之後的殘差）。

那 dfAS 是多少？課本用一個漂亮的「減法」推導：

用「自由度也可以相加」反推
已知：dftotal = dfA + dfS + dfAS
且：dftotal = AS − 1，dfA = A − 1，dfS = S − 1

所以：dfAS = (AS − 1) − (A − 1) − (S − 1) = (A − 1)(S − 1)
展開驗證：AS − 1 − A + 1 − S + 1 = AS − A − S + 1 = (A−1)(S−1) ✓

💡 也可以用第十六章的規則直接讀出來：來源名稱是 AS（交互作用），所以 df = (A−1)(S−1)。
變異來源dfSS 的理解公式當誤差用？
𝒜（實驗效果）A − 1S·Σ(Ma· − M··)²—
𝒮（個別差異）S − 1A·Σ(M·s − M··)²❌ 被挖出來丟掉
𝒜𝒮（殘差）(A−1)(S−1)ΣΣ(Yas−Ma·−M·s+M··)²✅ 這就是新誤差
總和AS − 1ΣΣ(Yas − M··)²—
🤔 為什麼挖掉 SSS 會讓 F 變大？（兩個力量同時作用）
① 分子的 SS 不變，但分母的 SS 變小了。
SSAS = SSS(A) − SSS。個別差異越大，挖掉的越多。

② 但自由度也變少了：dfS(A) = A(S−1) → dfAS = (A−1)(S−1)。

哪個力量贏？看 §5 的實例：SS 從 448 掉到 48（少了 89%），df 從 16 掉到 12（只少了 25%）。
所以 MS 從 28.00 暴跌到 4.00 → F 從 1.07 飆到 7.50。

⚠️ 但要注意：如果個別差異很小（SSS ≈ 0），挖掉它沒撈到什麼好處，自由度損失反而讓你吃虧。所以重複量數不是永遠比較好——它在「個別差異大」的情境下才有優勢。
§5

完整實例：5 位受試者 × 4 個條件

課本 Table 18.3：A = 4 個水準、S = 5 位受試者（如果用受試者間設計要 20 人）。

📈 每位受試者的「個人折線」——看出個別差異有多大
👀 五條線整體高低差很多（s₁ 平均 27，s₅ 平均 15），但形狀卻很相似（都是往右下走）。
這正是重複量數設計最理想的情況：個別差異大（可以挖掉很多）、但每個人的反應模式一致（殘差小）。

§7

分數模型：一個混淆無法解開

𝒮 × 𝒜 的分數模型（Model I：𝒜 固定）
Yas = μ·· + αa + ss + αsas + eas
αa：𝒜 第 a 水準的效果（固定）
ss：第 s 位受試者的效果（隨機——受試者永遠是隨機因子）
αsas：這位受試者對這個條件的特殊反應（交互作用）
eas：實驗誤差

約束條件：Σαa = 0、Σaαsas = 0、E{ss} = 0 且 E{s²s} = σ²s、E{eas} = 0 且 E{e²as} = σ²e
🔒 一個解不開的混淆：注意最後兩項的下標都是 as

αsas（交互作用）與 eas（誤差）用了相同的下標——這不是筆誤，而是課本刻意的提醒：
它們永遠同進同出，無法分離。

為什麼？因為每位受試者在每個條件下只有一個分數。要分離「他對這個條件的特殊反應」與「隨機誤差」，你至少要讓他在同一條件下測兩次——但那就變成另一種設計了。

實務上的做法：課本說，可以採取一個保守的估計——假設 αs 項為 0，那麼 MSAS 就純粹是誤差。但要記得這只是權宜之計。
期望均方（EMS）：解釋了為什麼分母要用 MSAS
E{MSA} = σ²e + σ²as + S·θ²a
E{MSS} = σ²e + A·σ²s
E{MSAS} = σ²e + σ²as
檢定 𝒜 時要找什麼分母？要找一個「除了 S·θ²a 以外，跟 E{MSA} 完全一樣」的均方。

・E{MSAS} = σ²e + σ²as → 完全對上！H₀ 為真時（θ²a = 0）兩者期望值相同 → F ≈ 1 ✓
・E{MSS} 含有 A·σ²s，對不上 ✗

📌 這再次印證第十六章學的技巧：分母不是用猜的，是比對 EMS 找出來的。
也順帶說明了為什麼 𝒮 × 𝒜 設計的邏輯跟 Model II（兩因子皆隨機）一樣——因為 𝒮 本來就是隨機因子。
§8

效果量：三個來源，三個 R²

分數的分解可以寫成（跟第十六章同樣的形式）：

Yas = M·· + Aa + Ss + ASas

其中 Aa = (Ma· − M··)、Ss = (M·s − M··)、ASas = (Yas − Ma· − M·s + M··)。

實驗效果
R²Y·A = SSA / SStotal
本例 90/538 = .167
個別差異
R²Y·S = SSS / SStotal
本例 400/538 = .743
殘差
R²Y·AS = SSAS / SStotal
本例 48/538 = .089
F 與 R² 的關係
F = (R²Y·A / R²Y·AS) × (dfAS / dfA)
(.167/.089)×(12/3) = 7.50 ✓
🥧 變異的三等分：看清楚「個別差異」佔了多大比重
😮 個別差異佔了 74.3%！這份資料的變異，絕大部分根本不是實驗造成的，而是「人跟人本來就不一樣」。

如果用受試者間設計，這 74.3% 會全部算進誤差，把訊號淹沒。
重複量數設計把它整塊拿掉，所以剩下的訊噪比變得非常漂亮（.167 vs .089）。
§9

天下沒有白吃的午餐：四大風險

重複量數設計有這麼多好處，為什麼大家不全部都用它？因為「同一批人」這件事本身會製造新問題。

⚠️ 風險一：攜帶效應（carry-over effects）

前一個條件的經驗，汙染了後一個條件的表現。

課本的例子：想比較幾種識字教學法。一個已經學會閱讀的孩子，根本無法跟一個還沒學會的孩子相比——他不可能「重新變回文盲」再學第二種方法。

後果：自變數的效果與攜帶效應混淆（confounded），無法分離。

😰 課本的殘酷提醒：「隨機安排呈現順序，很遺憾，並不足以消除攜帶效應的風險。」
隨機化能消除「順序」的系統性偏誤，但無法讓「已經學會的東西」消失。

⚠️ 風險二：前後測設計的三個陷阱

情境：你設計了一套減少種族偏見的介入方案。先測偏見分數 → 施以介入 → 再測一次。分數下降了，可以宣稱介入有效嗎？

不一定！至少有三個混淆變數：

📅 歷史（history）
前後測之間發生的一連串事件，可能造成（或掩蓋）效果。例如一部轟動的電影、一則social新聞、一場經濟危機。
🌱 成熟（maturation）
時間一久，人就會改變。發展心理學研究尤其致命——很難區分實驗效果與自然成長。
🔬 測驗敏感化（sensitization）
光是「被測過」就會改變受試者——讓他意識到自己的態度，進而改變它（為了符合研究者期待、或符合自我形象）。

📌 特別容易中招的情境：使用固定樣本小組（panel）的研究——同一群人被反覆測試很長一段時間。他們會開始「扮演專家」：主動找資料、研究這個主題，使後測分數完全不能代表一般人。

⚠️ 風險三：回歸到平均數（regression toward the mean）

情境：為了讓效果明顯，你刻意挑「偏見最嚴重」的那群人來做介入。後測時分數果然下降了。這證明介入有效嗎？

不能！這可能只是「回歸到平均數」的統計假象。

任何測量 =
真實值 ＋ 隨機誤差→ 挑「極端高分」的人
＝同時挑到「誤差也特別大」的人→ 重測時誤差平均會變小
（大誤差比小誤差罕見）→ 分數「自動」靠近平均
製造出「有效果」的假象
📉 回歸到平均數模擬：資料完全隨機，但「極端組」看起來好像被治好了

⚠️ 風險四：實驗流失（experimental mortality）

重複量數需要受試者多次回來。中途退出的人往往不是隨機的——例如表現最差、最挫折的人最容易放棄。
剩下的樣本就不再能代表原本的母體了。

🛡️ 實務上怎麼降低這些風險？
① 對抗平衡（counterbalancing）：讓不同受試者以不同順序接受條件（例如拉丁方格設計），讓順序效應平均掉；
② 條件之間留足夠的間隔，降低攜帶效應；
③ 若攜帶效應本質上無法避免（像識字教學的例子）→ 老老實實用受試者間設計；
④ 前後測研究務必加控制組（只做前後測、不接受介入）——這樣歷史、成熟、敏感化、回歸平均的影響，兩組都會有，相減就抵消了。
§10

新的假設：球面性（sphericity）

第十一章的三大假設（常態性、變異數同質性、獨立性）依然適用。但重複量數設計多了一個全新的假設：

🔵 球面性的直觀說法

任兩個實驗條件之間的相關（或共變異數），對所有配對來說都要差不多。

換句話說：受試者的行為模式，在所有條件組合之間要相當一致。

這個假設又叫做 circularity（環狀性） 或 homogeneity of covariance（共變異數同質性）。

🤔 為什麼受試者間設計不需要這個假設？
因為在 𝒮(𝒜) 設計中，不同條件下的分數來自不同的人，彼此獨立——根本不存在「條件之間的相關」這回事。

但在重複量數設計中，同一個人的多個分數必然相關。問題是：這些相關的「強度」在不同配對之間是否一致？

典型的違反情境：相鄰的時間點相關高（第 1 次 vs 第 2 次），相隔遠的相關低（第 1 次 vs 第 6 次）。這在縱貫研究中幾乎必然發生。

課本建議的五個檢查步驟（由簡到繁）：

步驟做什麼
1看原始資料；更深入的做法是看殘差（Yas − Ma· − M·s + M··）
2把交互作用畫出來（第十六章 §7 的純交互作用圖）
3比較各個平方和（用本章 §8 的相關係數）
4⭐ 課本說這是最好的方法：算出所有條件配對的共變異數（或相關）。如果這些數字差很多，假設大概就不成立了。
5計算球面性指標 ε（§11）

§11

怎麼補救？Box 的 ε 與三種校正

💡 Box (1954) 的關鍵發現

球面性違反時，F 比值還是服從 Fisher 分配——只是自由度要打折扣。

ν₁ = ε(A − 1)　　ν₂ = ε(A − 1)(S − 1)

ε 介於 0 與 1 之間。ε 越小表示資料越不球面，自由度被砍得越兇，臨界值越高、越難顯著。
ε = 1 表示完美球面，不需要任何校正。

Box 的非球面性指標 ε
ε = (Σa ζa,a)² ／ [(A − 1) · Σa,a′ ζ²a,a′]
ζa,a′ 是母體共變異數矩陣的元素。分子是對角線總和（trace）的平方，分母是所有元素平方和乘上 (A−1)。

⚠️ 問題：母體共變異數矩陣我們不知道。所以必須從樣本估計——這就是 Greenhouse–Geisser 要處理的事。

① Greenhouse–Geisser 校正：ε̂

從樣本共變異數矩陣估出母體矩陣的方法叫做雙重置中（double-centering）：

雙重置中公式
sa,a′ = ta,a′ − t̄a,· − t̄a′,· + t̄··
ta,a′ 是樣本共變異數；t̄a,· 是第 a 列的平均；t̄·· 是整個矩陣的總平均。

看起來眼熟嗎？這跟第十六章的交互作用項 (Mab· − Ma·· − M·b· + M···) 是一模一樣的形式——都是「扣掉兩個邊際效應」。

課本的示範：s1,3 = 8 − 138 − 14 + 72 = −72
🔄 雙重置中前後的對照（點格子看計算）
用置中後的矩陣算 ε̂
ε̂ = (90 + 90 + 78 + 78)² ／ [3 × (90² + 54² + … + 66² + 78²)]

= 336² ／ (3 × 84,384) = 112,896 ／ 253,152 = .4460
校正後的自由度：
ν₁ = .4460 × 3 = 1.34　｜　ν₂ = .4460 × 3 × 4 = 5.35

用這組自由度重新查 F = 5.36 的機率 → p = .059　（不再顯著！）
若要用臨界值法，把自由度四捨五入成整數：ν₁ = 1、ν₂ = 5。

② 極端 Greenhouse–Geisser 校正（最保守）

Greenhouse & Geisser (1959) 還提出一個「最壞打算」的版本：直接假設 ε 是它可能的最小值，也就是 1/(A−1)。這會讓自由度掉到：

ν₁ = 1　，　ν₂ = S − 1 = 4　→　F = 5.36 的 p = .081

這是最保守的做法——型 II 錯誤的風險變高（真有效果也可能測不到）。

③ Huynh–Feldt 校正：ε̃（課本推薦）

Huynh & Feldt (1976) 的改良估計
ε̃ = [S(A − 1)ε̂ − 2] ／ {(A − 1)[S − 1 − (A − 1)ε̂]}
代入本例：ε̃ = [5 × 3 × .4460 − 2] ／ {3 × [5 − 1 − 3 × .4460]} = .5872

校正後自由度：ν₁ = .5872 × 3 = 1.76　｜　ν₂ = .5872 × 3 × 4 = 7.04
→ F = 5.36 的 p = .041（顯著！）

📌 課本的建議：一般而言 Huynh–Feldt 較佳，因為它的檢定力較高（Greenhouse–Geisser 太保守）。
⚖️ 四種做法的對照：同一個 F = 5.36，結論卻可能相反
😰 看懂這張圖，你就懂了球面性為什麼重要：
完全相同的資料、完全相同的 F 值 5.36，但因為用了不同的校正：
・不校正 → p = .018（顯著）
・Huynh–Feldt → p = .041（還是顯著）
・Greenhouse–Geisser → p = .059（不顯著了）
・極端 GG → p = .081（更不顯著）

所以論文中必須明確交代用了哪一種校正——這不是細節，這會改變結論。

🧠 第三個實例：順向干擾
