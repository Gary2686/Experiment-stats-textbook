二因子混合設計

一個因子重複、一個因子不重複——最常見、最實用的實驗設計。受試者巢套在 𝒜 之下，卻與 ℬ 完全交叉。

§1

三種二因子設計，擺法完全不同

到目前為止我們看過兩種極端：完全不重複（第十六章 𝒮(𝒜×ℬ)）與完全重複（第十九章 𝒮×𝒜×ℬ）。本章是兩者的折衷。

設計符號怎麼讀：𝒮(𝒜) × ℬ ＝「受試者巢套在 𝒜 之下，但與 ℬ 交叉」。
白話：每個人只屬於一個 𝒜 水準，但跑過所有 ℬ 水準。

🧩 同樣是 A=2 × B=4 的 8 個條件，三種設計各需要幾個人？（點切換）
𝒮 × 𝒜 × ℬ

𝒮(𝒜) × ℬ
10 人

40 人

🎯 為什麼混合設計最常見？
因為很多因子根本不可能重複量數。年齡、性別、科系、臨床診斷——這些是第一章講的標籤變數（tag variable），一個人是五歲就不可能同時是十二歲。

只要實驗中有一個標籤變數，設計就自動變成混合設計。
§2

bat 與 hat：孩子什麼時候開始「在心裡唸出聲」？

複製 Conrad (1972) 的實驗。理論問題：幼兒在短期記憶中會不會使用語音編碼？

👶

因子 𝒜：年齡（受試者間）

a₁ 五歲（5 人）　／　a₂ 十二歲（5 人）
標籤變數 → 受試者巢套在它之下

🔊

因子 ℬ：語音相似性（受試者內）

b₁ 語音相似（hat / cat）
b₂ 語音不相似（horse / chair）
每個孩子兩種都做 → 與 𝒮 交叉

程序：給孩子看 100 對圖片（事先測試確保孩子對每張圖的命名一致——貓的圖一定叫「貓」，不會叫「寵物」）。看完後把圖翻面蓋住，再給孩子一組一模一樣的圖片，請他們放在對應的位置上。
依變數 = 正確配對的對數。

🔮 Conrad 的推理：預測一個交互作用

如果大孩子會用語音編碼複誦 → 語音相似的配對會互相干擾 → 相似條件表現較差。

如果小孩子不用語音編碼 → 語音相似與否對他們沒有影響 → 兩個條件表現一樣。

再加上一個很平凡的預測：大孩子整體表現本來就比小孩子好（年齡主效果）。

🎯 關鍵在交互作用：年齡主效果是「廢話」，真正檢驗理論的是「語音相似性的效果是否隨年齡改變」。
這呼應第十五章的核心主張：交互作用才是理論的試金石。

📈 結果（課本 Figure 20.1 重繪）：兩條線呈扇形張開
👀 先用眼睛看：五歲組兩條件差 16 − 14 = 2 分（幾乎沒差）；十二歲組差 36 − 26 = 10 分（差很多）。

§3

五個變異來源：兩個是新面孔

混合設計的來源數（5 個）介於完全不重複（3 個）與完全重複（7 個）之間。其中 𝒮(𝒜) 與 ℬ𝒮(𝒜) 是本章新出現的。

🔗 兩個新來源是怎麼來的？它們是完全重複設計中幾個來源的「合併」
混合設計與完全重複設計的對應關係（課本的重要洞見）
SSS(A) = SSS + SSAS　　　SSBS(A) = SSBS + SSABS
為什麼會合併？因為受試者巢套在 𝒜 之下 → 一個人只出現在一個 𝒜 水準 → 無法把「這個人本身的效果（ss）」跟「這個人對 𝒜 的特殊反應（αsas）」分開。兩者永遠綁在一起 → 合併成 ss(a)。

同理，β sbs 與 αβsabs 也無法分離 → 合併成 βsbs(a)。

🔧 實務小撇步：自由度也以同樣方式相加。所以如果手上的統計軟體不支援部分重複設計，可以先跑完全重複設計、再把對應的 SS 跟 df 加起來。
來源自由度本例理解公式

總和ABS − 119ΣΣΣ(Yabs − M···)²
🪄 課本的那句金句

「一個來源的名字，就告訴了你它的平方和、自由度、均方要怎麼算。」

比較三種設計你會發現：實驗來源（𝒜、ℬ、𝒜ℬ）在三種設計裡的算法一模一樣，變的只有「殘差項」。

・𝒮(𝒜) 的名字說「受試者在 𝒜 之內」→ 公式就是「在每個 a 之內，比較各受試者平均與該組平均」：B·ΣΣ(Ma·s − Ma··)²
・ℬ𝒮(𝒜) 的名字說「ℬ 與（𝒜 之內的受試者）的交互作用」→ 公式就是把 ℬ 與 𝒮(𝒜) 的交互作用寫出來。

🔑 一句話記住規則：

📝 課本示範的「結果段落」怎麼寫

本研究以年齡 × 語音相似性的變異數分析處理資料，其中年齡（五歲 vs 十二歲）為受試者間因子，語音相似性（相似 vs 不相似）為受試者內因子。

年齡的效果非常明確，F(1, 8) = 32.00, MSe = 40.00, p < .01。
預期中的年齡 × 語音相似性交互作用同樣高度可靠，F(1, 8) = 20.00, MSe = 4.00, p < .01。
語音相似性的主效果也達顯著，F(1, 8) = 45.00, MSe = 4.00, p < .01，但如 Figure 20.1 所示，由於語音相似性與年齡之間存在強烈的交互作用，將它解讀為主效果是需要謹慎的。

🔍 請特別注意最後那句話的寫法。這是專業論文的標準做法：
當交互作用顯著時，主效果的解讀就變得危險——因為「平均而言語音相似讓表現下降 6 分」這句話對五歲組（只降 2 分）根本不成立。

正確的描述是：「語音相似性的效果取決於年齡：對十二歲組造成 10 分的損失，對五歲組只有 2 分。」
👉 這呼應第十五章 §6 的規則：交互作用顯著時，應優先報告單純主效果而非主效果。

🤔 為什麼 𝒜 的 R² = .68 這麼大，F 卻「只有」32，比 ℬ 的 45 還小？
因為兩者用的分母完全不同。

・𝒜：SS = 1,280（佔 67.7%），但分母 MSS(A) = 40.00 → F = 32.00
・ℬ：SS = 180（只佔 9.5%），但分母 MSBS(A) = 4.00 → F = 45.00

效果量（R²）與統計顯著性（F）回答的是不同問題：
R² 問「這個因子解釋了多少變異」；F 問「相對於它自己的誤差，這個效果有多穩定」。

年齡的效果雖然巨大，但孩子之間的個別差異也很大（MSS(A) = 40）；
語音相似性的效果雖然小，但同一個孩子在兩種條件下的表現非常穩定（MSBS(A) = 4）。

這正是重複量數設計的威力——把個別差異從誤差中拿掉。
§7

分數模型：少了一個交互作用項

𝒮(𝒜) × ℬ 的分數模型（Model I）
Yabs = μ··· + αa + βb + ss(a) + αβab + βsbs(a) + ebs(a)
兩個新項目：ss(a)（巢套在 a 之內的受試者）與 βsbs(a)。括號提醒我們：這個受試者只被指派到一個 𝒜 水準。

⚠️ 注意少了什麼：沒有 αsas 這一項！
因為一個人只出現在一個 𝒜 水準 → 根本不可能估計「人與 𝒜 的交互作用」。它已經被吸收進 ss(a) 裡。

最後 βsbs(a) 與 ebs(a) 下標相同 → 照例混淆（與第十八、十九章同一個道理）。
📐 期望均方（Model I）：為什麼分母要這樣配
來源E{MS}H₀ 為真時剩下
𝒜σ²e + B·σ²s(a) + BS·θ²aσ²e + B·σ²s(a) ＝ E{MSS(A)} ✓
𝒮(𝒜)σ²e + B·σ²s(a)（無對應 → 不可檢定）
ℬσ²e + σ²bs(a) + AS·θ²bσ²e + σ²bs(a) ＝ E{MSBS(A)} ✓
𝒜ℬσ²e + σ²bs(a) + S·θ²abσ²e + σ²bs(a) ＝ E{MSBS(A)} ✓
ℬ𝒮(𝒜)σ²e + σ²bs(a)（無對應 → 不可檢定）
💡 看出規律了嗎？𝒜 的 EMS 裡含有 B·σ²s(a)（受試者的變異），所以必須用含有同樣這一項的 MSS(A) 當分母。
而 ℬ 跟 𝒜ℬ 的 EMS 裡含的是 σ²bs(a)，所以用 MSBS(A)。

👉 分母永遠是「把要檢定的那一項（θ²）拿掉之後，剩下來的那一串」。這條規則從第十六章一路通用到第二十二章。
§8

固定 vs 隨機：四種組合，四張不同的檢定表

𝒮(𝒜) × ℬ 設計有個特別之處：𝒜 與 ℬ 的角色並不對稱（不像 𝒮(𝒜×ℬ) 與 𝒮×𝒜×ℬ）。所以 Model III 必須分成兩種情況分別討論。

🎲 四種模型的檢定表（點切換）
⚠️ 課本的結論：「這兩張表之間的巨大差異，顯示了區分固定與隨機因子的重要性。統計模型的正確選擇，明顯取決於這個決定。」

注意 III-a 與 III-b 的差異有多大：
・III-a（𝒜 隨機、ℬ 固定）：𝒜 用 MSS(A)、ℬ 用 MSAB、𝒜ℬ 用 MSBS(A) → 三個不同分母
・III-b（𝒜 固定、ℬ 隨機）：𝒜 完全檢定不了，而 𝒮(𝒜)、ℬ、𝒜ℬ 全部用 MSBS(A)

同一份資料，光是換個模型假設，主效果就從 F = 32.00 變成「無法檢定」。
🤔 Model II 時 𝒜 檢定不了，怎麼辦？
用第十九章學過的 Quasi-F。當 𝒜、ℬ 都是隨機因子時：
E{MSA} = σ²e + σ²bs(a) + S·σ²ab + B·σ²s(a) + BS·σ²a

H₀ 下剩 σ²e + σ²bs(a) + S·σ²ab + B·σ²s(a)，沒有單一均方對得上。組合出來：
MS′test,A = MSAB + MSS(A) − MSBS(A)

驗算期望值：(σ²e+σ²bs(a)+Sσ²ab) + (σ²e+Bσ²s(a)) − (σ²e+σ²bs(a)) = σ²e + σ²bs(a) + Sσ²ab + Bσ²s(a) ✓

代入本例的數字：MS′ = 80 + 40 − 4 = 116.00；F′A = 1280 / 116 = 11.03
ν₂ ≈ 116² / [(80²/1) + (40²/8) + (4²/8)] = 13,456 / 6,602 = 2.04 → 四捨五入 ν₂ = 2

相較於 Model I 的 F = 32.00（ν₂ = 8），檢定力大幅下降。
§9

效果量與效度條件

強度係數（coefficient of intensity）
R²Y·AB = SSAB / SStotal　　R²Y·BS(A) = SSBS(A) / SStotal
每一個可辨識的變異來源都可以算：把它的平方和除以總平方和。做法跟前面各章完全一樣。

也可以算「偏相關係數」：例如若想評估 𝒜 相對於實驗來源（𝒜 + ℬ + 𝒜ℬ）的重要性，就用
SSA / (SSA + SSB + SSAB) = 1280 / 1540 = .831
課本說：任何組合都合理，只要它能回答研究者真正關心的問題。

✅ 效度條件：多了一條

混合設計可看成 𝒮(𝒜×ℬ) 與 𝒮×𝒜×ℬ 的折衷，所以這兩者的技術假設都要成立（常態性、變異數同質性、球形性……見第十二、十八章）。

但還要多一條：

📋 共變異數矩陣同質性（homogeneity of the covariance matrices）

意思是：由因子 ℬ 算出來的共變異數矩陣，應該與 𝒜 的水準無關。

換句話說：「ℬ 各水準之間的相關結構」不能隨 𝒜 改變。

用本例講白話：五歲組「相似條件與不相似條件之間的相關」，應該跟十二歲組的相關差不多。如果五歲組兩條件高度相關、十二歲組卻毫不相關，這個假設就被違反了。

也可以說成：「ℬ 的共變異結構與因子 𝒜 之間沒有交互作用」。
檢驗與校正方法可參考第十八章 §12 提到的文獻（Box's ε、Greenhouse–Geisser 等）。
§10

處方箋：哪個因子該拿來重複量數？

𝒮(𝒜) × ℬ 可以用兩種方式理解：

🧩

看法一：好幾個 𝒮 × ℬ 併排

在每一個 𝒜 水準裡面，都是一個完整的 𝒮 × ℬ 重複量數設計。五歲組一個、十二歲組一個，並排放。

看法二：𝒮(𝒜) 做了重複測量

把一個 𝒮(𝒜) 單因子設計（第七～十四章）拿來，對每個人重複測量 B 次。

💊 課本的實用建議

受試者內因子 ℬ 的效果，通常比受試者間因子 𝒜 的效果更容易偵測到。

看本例就知道：MSBS(A) = 4.00 vs MSS(A) = 40.00——受試者內的誤差只有受試者間的十分之一。

🎯 所以：如果可以選，把「你最在乎、最需要檢定力」的那個因子設計成重複量數。

⚠️ 但常常由不得你選：當因子是標籤變數或受試者變數（年齡、性別、臨床組別）時，根本不可能做重複量數——沒有人能同時是五歲和十二歲。

本例就是如此：年齡只能是受試者間因子，所以它的檢定力天生就比較弱。能做的是增加每組人數（提高 dfS(A)）。

❓ 課本的關鍵問題

✶ 𝒮(𝒜) × ℬ 設計提供了什麼優點？
1. 人力折衷。同樣 8 個條件：完全不重複要 40 人、完全重複只要 5 人、混合設計要 10 人。在「受試者難找」與「每人負擔太重」之間取得平衡。

2. 受試者內因子享有高檢定力。ℬ 與 𝒜ℬ 的誤差（MSBS(A) = 4.00）遠小於受試者間誤差（40.00），因為個別差異被拿掉了。

3. 可以容納無法重複的因子。年齡、性別、臨床組別這類標籤變數只能是受試者間因子，混合設計讓它們能與重複量數因子並存。

4. 攜帶效應風險較低。每人只跑 B 個條件（而非 A×B 個），練習、疲勞、順序效應比完全重複設計輕。
✶ 為什麼決定因子是固定或隨機時需要特別謹慎？
因為 𝒜 與 ℬ 的角色不對稱，四種模型組合會產生四張截然不同的檢定表：

・Model I：𝒜 用 MSS(A)，ℬ 與 𝒜ℬ 用 MSBS(A)
・Model II：𝒜 完全無法檢定，需要 Quasi-F
・III-a（𝒜 隨機、ℬ 固定）：ℬ 改用 MSAB 當分母
・III-b（𝒜 固定、ℬ 隨機）：𝒜 無法檢定，但 𝒮(𝒜) 反而可以用 MSBS(A) 檢定

同一份資料，FA 可能是 32.00、11.03（Quasi-F），或是「無法檢定」。
這個決定必須在設計階段依據第十章的判準（「複製時會用一模一樣的水準嗎？」）想清楚，而不是看完資料再選對自己有利的。
