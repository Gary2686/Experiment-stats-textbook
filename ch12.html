§1

omnibus F 的不足：問了一個沒人在乎的問題

回想第八章的 Romeo and Juliet：F(3, 16) = 7.22, p < .01。很漂亮，但它只回答了一個問題——「四組的平均數不全部相同」。

可是作者真正想證明的是：「事前給脈絡的第 2 組，表現優於其他三組」；他還想確認「事後給脈絡的第 3 組跟無脈絡的第 1 組沒有差異」（用來殺掉對手理論）。

omnibus F 對這兩個問題，一個都答不出來。

📋

計畫性比較（a priori）

實驗開跑前就決定要做的比較，直接來自研究假設或對立理論。

數量通常很少，因為理論只預測幾件事。
👉 這是本章的主題。

🔍

事後比較（post hoc）

看完資料後才決定要比什麼。例如「把最好的組跟最差的組比一比」——這種比較只有拿到資料才知道要比誰。

目的是確認「意料之外的樣態」是否可靠。
👉 第十四章的主題。

🔢 一個關鍵數字：A − 1
一組正交（互相獨立）的比較，最多只能有 A − 1 個。
巧的是，A − 1 正好是 dfA——這不是巧合。§7 會看到：這 A − 1 個對比的 SS 加起來剛好等於 SSA，等於把實驗效果切成 A − 1 片，每片一個自由度。
🛠️ 所有類型的比較都遵循同樣三步驟：
① 把研究假設形式化成一組權重 Ca
② 計算 Fcomp（就是 F 比值，只是分子換成對比的均方）
③ 評估 Fcomp 的機率

只有第③步會因比較的類型而不同（正交 vs 非正交 vs 事後）。前兩步永遠一樣。
§2

什麼是對比（contrast）？

用課本的例子：研究鎮靜劑對電玩表現的影響，設計了四組——

組別內容
第 1 組：控制組什麼都不給，直接玩電玩
第 2 組：安慰劑組給一顆假藥
第 3 組：紅色藥丸組鎮靜劑裝在鮮紅色藥丸裡
第 4 組：藍色藥丸組同樣的鎮靜劑，裝在淡藍色藥丸裡

第一個研究問題：不管什麼顏色，鎮靜劑本身有效果嗎？
翻譯成統計語言：「兩個吃藥組的平均，跟安慰劑組相同嗎？」

從研究假設到對比：三次改寫
H₀ : μ₂ = (μ₃ + μ₄) ／ 2　（原始想法）

H₀ : 2μ₂ = μ₃ + μ₄　（去掉分數）

H₀ : 2μ₂ − μ₃ − μ₄ = 0　（全部移到一邊）
最後一行左邊那個式子，就是對比（contrast），記作希臘字母 ψ（讀作 sigh，就是 psychology 的那個 psy）。
「對比」這個名字來自：我們把平均數分成正號與負號兩群，讓它們互相對抗。

寫得更一般化一點，把每一組的平均都乘上一個權重：

對比的通式
ψ₁ = (0 × μ₁) + (2 × μ₂) + (−1 × μ₃) + (−1 × μ₄)
權重記作 Ca,c（a = 組別編號，c = 第幾個對比）。這裡：
C1,1 = 0（控制組沒被牽涉進來，所以權重是 0）、C2,1 = 2、C3,1 = −1、C4,1 = −1

H₀ : ψ₁ = 0　vs　H₁ : ψ₁ ≠ 0

註：有些課本（Rosenthal & Rosnow, 1985; Estes, 1991）用 λa 代替 Ca，意思相同。
📏 對比的鐵律：權重加起來必須是 0
Σa Ca = 0

檢查 ψ₁：0 + 2 + (−1) + (−1) = 0 ✓

為什麼一定要這樣？因為對比要問的是「這群 vs 那群有沒有差」，而不是「整體水準高不高」。若權重和不為 0，這個式子就會被總平均污染，變成在問別的問題了。

第二個研究問題：有沒有安慰劑效果？→ 比較控制組與安慰劑組：

ψ₂ = (1 × μ₁) + (−1 × μ₂) + (0 × μ₃) + (0 × μ₄)　→　C = (1, −1, 0, 0)，Σ = 0 ✓

🎩 ψ 與 ψ̂ 的區別：ψ 是母體的真值（用 μ 算的，永遠不知道）；ψ̂（sigh-hat，戴帽子）是用樣本平均數算出來的估計值：
ψ̂₁ = 2M₂. − M₃. − M₄.　　ψ̂₂ = M₁. − M₂.
§3

親手建構對比：把假設翻譯成數字

翻譯的訣竅只有三條，練幾次就會了：

1

把要比較的兩群分成「正號組」與「負號組」

沒有參與這次比較的組，權重給 0。

2

每一邊的權重 = 「對面那一邊的組數」

例：1 組 vs 3 組 → 正號那組給 +3，負號那三組各給 −1。
例：2 組 vs 3 組 → 正號兩組各給 +3，負號三組各給 −2。

3

檢查 ΣCa = 0

(+3) + (−1)×3 = 0 ✓　　(+3)×2 + (−2)×3 = 6 − 6 = 0 ✓

💡 權重可以整組乘上任意常數（例如 (2,−1,−1) 和 (4,−2,−2) 檢定的是同一件事），F 值完全不變。習慣上用最小整數。

🎮 對比建構器：自己填權重，即時檢查與計算（Smith 實驗資料，S = 10、MSS(A) = 32）
§4

正交性：兩個對比互不重疊

如果你做好幾個對比，它們最好互相獨立——問的是完全不重疊的問題。用統計的話說，兩個對比的相關係數為 0，也就是正交（orthogonal）。

正交性的判準（等組人數時）
Σa Ca,1 × Ca,2 = 0
把兩個對比的權重逐組相乘再加總。得到 0 就是正交。

🔗 這個式子其實就是第二章的交叉乘積和（SCP）——相關係數的分子。分子為 0 ⟹ 相關為 0 ⟹ 兩個對比互相獨立。

回到第八章的 Smith 記憶實驗（5 組），課本設計了 4 個研究假設：

H1
「有正確脈絡」的組（第 1 組相同脈絡、第 3 組想像脈絡、第 4 組照片脈絡）表現優於「沒有正確脈絡」的組（第 2 組不同脈絡、第 5 組安慰劑）。
H2
「相同脈絡」（真的回到原場景）與「模擬脈絡」（想像／照片）有差異。
H3
「想像脈絡」與「照片脈絡」有差異。
H4
「不同脈絡」與「安慰劑」有差異。
對比1. 相同2. 不同3. 想像4. 照片5. 安慰劑ΣCa
ψ₁（1,3,4 vs 2,5）+2−3+2+2−30 ✓
ψ₂（1 vs 3,4）+20−1−100 ✓
ψ₃（3 vs 4）00+1−100 ✓
ψ₄（2 vs 5）0+100−10 ✓
🔢 對比的個數 = 4 = A − 1 = dfA。這是正交對比家族的上限——再多就一定會有重疊。
⊥ 正交性檢查矩陣：任兩個對比的權重乘積和（點格子看計算過程）
🍰 為什麼正交這麼重要？

因為正交 ⟹ SSψ1 + SSψ2 + … + SSψ(A−1) = SSA。

也就是說，一組正交對比把「實驗效果」這塊蛋糕不重不漏地切成 A − 1 片，每片剛好 1 個自由度。你可以清楚地說：「這個效果有 96% 來自第一個對比。」

如果對比之間不正交（第十三章的主題），SS 就會互相重疊、加起來超過 SSA——這正是第六章「非正交多元迴歸」的老問題，只是換了個場景重演。

§5

危險：做越多比較，越容易「撿到」假發現

每做一個檢定，就有 α 的機率犯型 I 錯誤（把不存在的效果說成存在）。做 4 個檢定呢？

α 的兩種意義
α[PF] = 1 − (1 − α[PC])C
・α[PC]（per comparison）：單一個比較的型 I 錯誤率
・α[PF]（per family）：整組比較中至少犯一次型 I 錯誤的機率
・C：比較的個數

例：做 4 個比較，每個都用 α = .05 → α[PF] = 1 − .95⁴ = .1855
你以為冒 5% 的險，實際上接近 19%！
📈 α 膨脹曲線：做越多比較，「至少一次誤判」的機率飆得多快
4

🎩 統計學的經典笑話：船長的年齡

有人給小學生出了這樣一道題：「一艘船上有 26 隻綿羊和 10 隻山羊。請問船長幾歲？」

令人震驚的是，很多孩子會認真作答：「36 歲。」——他們假設題目一定有答案，於是把手上的數字硬湊出一個。

這跟統計有什麼關係？如果你對一堆沒有理論根據的比較全部做一遍檢定，總會有一兩個「顯著」。你會忍不住替它編一個解釋——就像孩子替船長編了個年齡。

但那個顯著只是統計的偽影（artifact），不是發現。這正是為什麼「計畫性比較」強調：比較必須來自理論，而且必須在看資料之前就決定好。

§6

解方：Šidák 與 Bonferroni 校正

既然做 C 個比較會讓整體錯誤率膨脹，那就反過來把每個比較的門檻調嚴，使整體維持在想要的水準。

Šidák 公式（精確解）
α[PC] = 1 − (1 − α[PF])1／C
把膨脹公式反解出來即可。假設各比較互相獨立（正交）時成立。

例：想讓 α[PF] = .05，做 C = 4 個比較 → α[PC] = 1 − (1 − .05)1/4 = .0127
Bonferroni／Boole／Dunn 不等式（近似解）
α[PC] ≈ α[PF] ／ C
例：.05 ／ 4 = .0125　（跟精確值 .0127 幾乎一樣）

兩者的關係：　1 − (1 − α[PF])1/C ≥ α[PF]／C
所以 Bonferroni 永遠比 Šidák 更保守（門檻更嚴、更容易漏掉真效果）。
🎯

該用哪一個？

理論上該用 Šidák——它是精確解，Bonferroni 只是近似且偏悲觀。

但 Bonferroni 更有名、更常被引用，主要是歷史因素：在沒有電腦的年代，除法比開 C 次方好算太多了。

💻

為什麼現在很重要？

校正後的 α 會變成 .0127 這種怪數字，傳統的 F 表只印 .05 和 .01，根本查不到。

這正是「電腦要能直接給出精確 p 值」在現代如此重要的理由。

🤷 但課本的態度其實相當務實：
「目前的慣例是把每個對比當成整個分析中唯一的對比來檢定」——也就是不做校正，直接用 α = .05 或 .01。

理由：計畫性正交比較通常源自對立理論的競爭。這時真正重要的是「哪個理論被資料支持、哪個被排除」，而不是嚴格控制家族錯誤率。而且對比數量本來就很少（≤ A−1）。

👉 實務建議：報告時把校正與否寫清楚。做了校正就說用哪個方法；沒做就說明比較是事前計畫且數量有限。透明比正確更重要。
§7

計算對比的平方和 SSψ

一個對比本質上就是「把資料重新分成正號、負號兩堆」的迷你 ANOVA。所以它只有 1 個自由度（兩堆嘛）。但誤差項要用完整實驗的 MSS(A)——因為那用上了全部資料，是誤差最好的估計。

對比平方和（最常用的形式）
SSψ = S(Σ CaMa·)² ／ Σ C²a = S·ψ̂² ／ Σ C²a
S = 每組人數；ψ̂ = Σ CaMa·（把權重乘上組平均再加總）

用組總和 Ya· 的等價版本：　SSψ = (Σ CaYa·)² ／ (S · Σ C²a)
因為 dfψ = 1，所以均方等於平方和
MSψ = SSψ ／ 1 = SSψ　　⟹　　Fψ = SSψ ／ MSS(A)
檢定時查 F 分配，ν₁ = 1、ν₂ = A(S − 1)。
注意：這只對「對比」成立。§10 的「次設計比較」可以有多個自由度，那時 MS ≠ SS。
🔗 對比其實也是迴歸（第九章的回音）

把權重 Ca 看成「對各組分數的預測值」，就可以算 Ca 與 Yas 的相關：

R²Y·ψ = SSψ ／ SStotal

這個係數告訴你「這個對比解釋了整體變異的多少比例」——效果量的一種。

另一個更常用的版本是 SSψ ／ SSA：「這個對比佔了實驗效果的多少比例」。§8 會看到，Smith 實驗的第一個對比一個人就吃掉了 96% 的實驗效果。

§9

一個漂亮的性質：omnibus F 是各對比 F 的平均！

推導（用到「正交對比的 SS 加總 = SSA」）
Fomnibus = (SSA／(A−1)) ／ MSS(A) = (Σ SSψ／(A−1)) ／ MSS(A) = (1／(A−1)) · Σ Fψ
驗證 Smith 實驗：(21.094 + 0.000 + 0.625 + 0.156) ／ 4 = 21.875 ／ 4 = 5.469 ✓
正是 ANOVA 表上的 omnibus F！
⚠️ 「平均」帶來的兩個弔詭現象（課本特別提醒，實務上很常遇到）

① omnibus F 不顯著，但某個對比顯著
例：A = 4、S = 5、SSA = 90、MSS(A) = 10。
FA = (90/3)/10 = 3.00 < 3.24（臨界值）→ 不顯著
若某對比 SSψ = 50 → Fψ = 50/10 = 5.00 > 4.49（df=1,16 的臨界值）→ 顯著！
原因：omnibus 把 90 除以 3 攤平了；對比不必除（df=1），強度完整保留。被其他無效對比稀釋掉了。

② omnibus F 顯著，但沒有任何對比顯著
效果平均分散在多個對比上，每個都不夠強，但加起來夠。

👉 所以：不需要「先做 omnibus F 顯著了才能做對比」。計畫性比較源自理論，本來就該直接做。
§10

次設計分析：當問題需要不只 1 個自由度

回到鎮靜劑實驗，但改成：安慰劑組 + 三種不同劑型的鎮靜劑。研究者只關心兩個問題：

Q1
吃鎮靜劑（不管哪種劑型）會不會影響電玩表現？
→ 可以寫成一個對比：+3 −1 −1 −1
Q2
三種劑型之間有沒有差異？
→ 寫不成單一個對比！因為 H₀ : μ₂ = μ₃ = μ₄ 需要 2 個自由度。
🧩 解法：把兩個正交對比「加起來」

Q2 其實是在分析一個「次設計（sub-design）」——從 4 組的設計中抽出 3 組來做一個小型 S(A) 分析。3 組 → 2 個自由度 → 可以由 2 個正交對比組成：

注意 F 的自由度：比較 1 是 (1, 36)、比較 2 是 (2, 36)——分子自由度不同，臨界值當然也不同。這是次設計分析最容易出錯的地方。
📚 術語釐清：
・對比（contrast）＝ 自由度恰為 1 的比較
・比較（comparison）／次設計（sub-design）＝ 可以有多個自由度
所以「所有對比都是比較，但不是所有比較都是對比」。當 df > 1 時，MScomp = SScomp ／ dfcomp，不能再偷懶說 MS = SS。
§11

趨勢分析：當自變數是「量」的時候

如果自變數是數量（藥物劑量、練習次數、酒精濃度），我們感興趣的往往不是「哪組跟哪組不同」，而是「整體呈現什麼形狀」——直線上升？先升後降？波浪型？

做法出奇地簡單：把每種「形狀」寫成一組對比權重，然後跑標準的對比分析。這些權重叫做正交多項式（orthogonal polynomials），課本附錄有現成的表。

📐 可以拆出幾種趨勢？A 個水準最多可以拆到 A − 1 次多項式——又是那個 dfA。5 組就是：線性、二次、三次、四次。
⚠️ 前提：設計必須平衡，且自變數的水準要等距（8%、10%、12%、14%、16% ✓）。不等距就得回頭用標準迴歸。

🍇 怎麼把兩個顯著趨勢講成一個故事

線性成分顯著（R² = .571）：整體而言，酒精濃度越高，評分越高。

二次成分也顯著（R² = .408）：但這條上升線是彎的——倒 U 型。

兩者合起來：酒精確實讓酒更討喜，但過了 14% 之後，再加酒精反而扣分。兩個成分合計解釋了實驗效果的 97.9%，三次與四次趨勢可以忽略。

💡 注意：如果只做 omnibus F，你只會知道「五組不一樣」；如果只做兩兩比較，你會得到一堆零碎的顯著性。只有趨勢分析能直接告訴你「形狀是倒 U 型，轉折在 14%」——這才是能寫進論文摘要的結論。

🔗 趨勢分析讓「對比」與「迴歸」的界線徹底模糊——因為我們正在評估「量的自變數」與依變數的關聯，這根本就是第五章的正交多元迴歸。
第九章說 ANOVA 是迴歸，這裡又一次印證：統計方法之間的牆，大多是術語砌出來的。
