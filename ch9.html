單因子 ANOVA
迴歸觀點

前八章我們學了兩套看似無關的技術：迴歸（第四～六章）與 ANOVA（第七～八章）。本章要揭穿一個秘密——它們根本是同一個東西，只是換了一套記號。

§1

核心點子：一句話講完這一章

迴歸分析要求自變數是數字（年齡、語速、飽和度）。但實驗的自變數往往是類別（控制組 / 實驗組）。這看起來是一道無法跨越的鴻溝——直到有人想到一個聰明的把戲：

把「你屬於哪一組」翻譯成數字的方法是……
X = 你那一組的平均數 Ma·
然後用這個 X 去跑普通的簡單線性迴歸。
結果會發現：斜率 b = 1、截距 a = 0、預測值 Ŷ = Ma·，
而且 SSregression = SSbetween、SSresidual = SSwithin、R² = η²、F 完全一樣。

這叫做平均數模型（mean model）。它的邏輯其實非常直觀：

🎯

為什麼用組平均當預測值？

如果我只知道你在實驗組，要猜你的分數，最合理的猜測就是實驗組的平均。這是「最小平方」意義下的最佳猜測。

📏

那「有效果」是什麼意思？

「自變數有效果」＝知道你的組別，比不知道更能預測你的分數。也就是：用組平均猜，比用總平均猜來得準。

🔗

所以 ANOVA 就是……

用「組別」預測「分數」的迴歸分析。R² 衡量這個預測有多準，F 檢定這個預測是否好過瞎猜。完全是迴歸的語言。

🎓 為什麼要學這件事？因為它揭示了統計學的深層結構：迴歸、ANOVA、t 檢定、變異數分析、共變數分析（ANCOVA）……全都是同一個一般線性模型（General Linear Model, GLM）的特例。理解這點之後，你會發現統計課本厚厚一本其實在講同一件事。

§3

第一步：把「組別」編碼成數字 X

迴歸需要一個數值的預測變數 X。我們的規則是：每個人的 X ＝ 他那一組的平均數。

受試者組別X（預測變數 = 組平均）Y（依變數）
1–5控制組41, 2, 5, 6, 6
6–10實驗組108, 8, 9, 11, 14

攤平來看，就是一個標準到不能再標準的迴歸資料集：

X： 4   4   4   4   4  10  10  10  10  10
Y： 1   2   5   6   6   8   8   9  11  14

✨ 這個編碼的第一個禮物

因為每組的 X 就是該組的平均，所以X 的平均會等於 Y 的平均，而且兩者都等於 ANOVA 的總平均：

MX = MY = M·· = 7

驗算：MX = (4×5 + 10×5)/10 = 70/10 = 7 ✓　MY = 70/10 = 7 ✓

📈 把資料畫成散佈圖（X = 組平均，Y = 實際分數）
👀 因為只有兩個 X 值（4 和 10），所有點都擠在兩條直線上。迴歸線恰好穿過兩個組平均——而且它的斜率剛好是 1（每往右走 1 格，預測值也上升 1 格）。

第四章的斜率公式
b = SCPXY ／ SSX = 90 ／ 90 = 1
SSX 和 SCPXY 竟然剛好相等——這不是巧合，§8 會證明它必然如此。
第四章的截距公式
aregression = MY − b·MX = 7 − 1 × 7 = 0
因為 MX = MY（§3 的禮物）且 b = 1，截距必然是 0。
於是迴歸方程式變成……
Ŷ = 0 + 1 × X = X = Ma·
預測值就等於預測變數，也就等於組平均。
換句話說：「用組平均去預測，得到的最佳預測值還是組平均。」

接下來用第四章的平方和分割。注意每一個 Ŷ 都是該組平均（4 或 10）：

迴歸平方和（預測值離總平均多遠）
SSregression = Σ(Ŷ − MY)² = 5×(4−7)² + 5×(10−7)² = 45 + 45 = 90.00
🔔 這不就是 SSbetween 嗎？因為 Ŷ = Ma·，這條公式跟 S·Σ(Ma· − M··)² 一模一樣。
殘差平方和（實際值離預測值多遠）
SSresidual = Σ(Y − Ŷ)² = (1−4)² + … + (14−10)² = 48.00
🔔 這不就是 SSwithin 嗎？因為 Ŷ = Ma·，殘差 (Y − Ŷ) 就是組內偏差 (Yas − Ma·)。
決定係數與 F
r²Y·X = SSreg ／ SStotal = 90 ／ 138 = .6522
F = [r² ／ (1 − r²)] × [dfresidual ／ dfregression]
  = [.6522 ／ .3478] × [8 ／ 1] = 1.8752 × 8 = 15.00 ✓

四個數字全部命中：138、90、48、15.00。零誤差。
§5

停下來想一想：這件事有多不尋常？

🎬 兩種觀點的視覺對照（點按鈕切換說法，資料完全不變）
🤯 同一張圖，兩種語言

・ANOVA 說：「組平均離總平均的距離」→ 組間變異
・迴歸說：「預測值離 Y 平均的距離」→ 迴歸解釋的變異
但因為 Ŷ = Ma·，這根本是同一段距離。

・ANOVA 說：「個人離自己組平均的距離」→ 組內變異（誤差）
・迴歸說：「實際值離預測值的距離」→ 殘差
同樣是同一段距離。

所以第七章那個「平方和可以相加」的定理，跟第四章的「SStotal = SSreg + SSres」
是同一個定理的兩種寫法。

§8

為什麼 b 必然等於 1？（證明，可跳過）

b = 1 看起來太巧了，會讓人懷疑是資料設計得剛好。課本用代數證明它對任何資料都成立。關鍵只有一步：證明 SCPYX = SSX，那麼 b = SCP/SS = 1 自動成立。

Step 1 · 改寫 SSX（記得 X = Ma·）
SSX = ΣΣ(Ma· − M··)² = S·Σ(Ma· − M··)²
展開平方並整理後得到：　SSX = S·ΣM²a· − A·S·M²··
Step 2 · 改寫 SCPYX
SCPYX = ΣΣ(Yas − M··)(Ma· − M··)
展開後會用到兩個關鍵事實：
① ΣsYas = S·Ma·（一組的總和 = 平均 × 人數）
② ΣΣYas = A·S·M··（全體總和 = 總平均 × 總人數）

代入化簡後得到：　SCPYX = S·ΣM²a· − A·S·M²··
Step 1 與 Step 2 的結果一模一樣，所以……
SCPYX = SSX　⟹　b = SCPYX ／ SSX = 1
接著代入截距公式：
aregression = MY − b·MX = M·· − 1 × M·· = 0

於是永遠有：Ŷ = 0 + 1 × Ma· = Ma·　Et voilà!
💡 這個證明真正說的是什麼

用組平均當預測變數時，最小平方法找不到比「組平均」更好的預測值——它想調整也調整不動（b 被鎖死在 1、a 被鎖死在 0）。

換句話說，這個證明等於在說：對於「只知道組別」的情境，組平均就是最小平方意義下的最佳預測。統計學家把這個叫做 mean model（平均數模型），在處理不平衡設計與複雜設計時特別重要。

§9

既然是同一件事，為什麼還要留兩套技術？

📜

理由一：歷史包袱

ANOVA 誕生於實驗心理學（Fisher 的農業實驗傳統）；迴歸誕生於社會與臨床心理學（Galton、Pearson 的個別差異傳統）。

兩個領域各自發展術語，互不相通。你想讀懂兩邊的論文，就得兩套都會。

🔧

理由二：各有順手的工具

・不平衡設計（各組人數不等）→ 用迴歸框架比較好處理
・多因子設計（第十六章之後）→ 用 ANOVA 框架比較清楚
・連續 + 類別混合（ANCOVA）→ 非迴歸框架不可

同一個問題，換個語言可能簡單十倍。

🎯 實務建議：不要把它們當成「兩種要二選一的方法」，而要當成同一個模型的兩種鏡頭。做研究時挑順手的那個；讀論文時兩種都要看得懂；被審稿人質疑時，能用另一種語言重述自己的分析，會非常加分。
§10

其他編碼方式（為第十二章鋪路）

「組平均」不是唯一的編碼方式。事實上只要每組給不同的數值，怎麼編都可以——SS、df、MS、F 全都不會變，只有 a 和 b 的數值會改變。

🔑 真正的規則：要用幾個預測變數？＝ 自變數有幾個自由度。

・2 組 → dfA = 1 → 需要 1 個預測變數（簡單迴歸就夠）
・4 組 → dfA = 3 → 需要 3 個預測變數（要用多元迴歸——第五、六章的工具！）

本章用「平均數模型」的最大好處是：不管幾組，永遠只需要一個預測變數，所以簡單迴歸就能處理。

3 個預測變數（= A − 1），最後一組全部給 0 當參照組。這正是 SPSS、R、Python 在跑 ANOVA 時檯面下實際做的事——你以為在跑 ANOVA，其實電腦在跑多元迴歸。

而「對比編碼」會在第十二章大放異彩：精心設計的一組對比，能讓你直接檢定「第 2 組 vs 其他三組」這種具體假設，而不只是 omnibus F。

📝 課本留的習題：拿心像實驗的資料，改用對比編碼（+1 / −1）和虛擬編碼（1 / 0）各跑一次迴歸，看看 a 和 b 變成多少，而 F 是不是仍然等於 15.00。（提示：對比編碼會得到 b = −3、a = 7；虛擬編碼會得到 b = −6、a = 10。試著解釋這些數字的意義。）
