§1

為什麼需要「分數模型」？

第七到第九章，我們把 ANOVA 的計算學得滾瓜爛熟。但有幾個問題一直被跳過：

❓

為什麼 F 服從 Fisher 分配？

第八章直接說「若 H₀ 為真，F 會服從 F 分配」，但憑什麼？要證明這件事，必須先寫下每個分數是怎麼產生的。

🎯

為什麼 F 在 H₀ 下會接近 1？

第七章用直覺說「分子分母都在估計誤差」。但這是直覺，不是證明。分數模型能給出嚴格的答案。

⚖️

R² 高估了多少？怎麼修正？

第八章警告 R² 會高估母體效果，卻沒給修正方法。ω² 與 ρ² 正是解答，而它們只能從分數模型導出。

🔬 觀念轉換：前幾章我們是「資料分析者」——手上有數字，想辦法拆解它。本章我們要當「資料產生者」——假想自己是老天爺，思考這些分數當初是怎麼被生出來的。這個視角轉換是所有推論統計的基礎。
§2

分數模型：一個分數的三個零件

起點還是第七章那個恆等式，只是這次我們把它移項——不是「拆解距離」，而是「組裝分數」：

從距離分割到分數組裝（只是移項而已）
(Yas − M··) = (Ma· − M··) + (Yas − Ma·)
把 M·· 移到右邊 →
Yas = M·· + (Ma· − M··) + (Yas − Ma·)
母體版本 · 這就是分數模型（SCORE MODEL）
Yas = μ·· + αa + es(a)
μ··　總平均
「不管你是誰、在哪一組」，這個依變數的基準水準。
估計值：M··
αa　處理效果
你被分到第 a 組這件事，讓你的分數偏移了多少。
估計值：Ma· − M··
es(a)　誤差
你這個人特有的偏離：測量誤差＋個別差異。
估計值：Yas − Ma·

用白話說，這個模型主張：

你的分數　＝　大家的基準　＋　你那組的處理效果　＋　你個人的隨機偏離

🔒 模型的兩個約束條件（很重要，後面會一直用到）

① Σαa = 0　所有處理效果加起來必須是 0。
   為什麼？因為 αa 定義為「離總平均的偏移」，離均差之和必然為 0。

② E{es(a)} = 0，Var{es(a)} = σ²e　誤差的期望值為 0、變異數為 σ²e（各組相同）。
   「各組相同」這一條就是第十一章要檢驗的「變異數同質性」假設。
🤔 誤差 es(a) 裡面到底裝了什麼？課本誠實地列出兩種可能：
① 測量誤差（儀器不準、實驗者抄錯數字）
② 受試者 × 處理的交互作用（不是每個人對操弄的反應都一樣，有人吃這套、有人不吃）

在 S(A) 設計中，這兩者永遠分不開——因為每個人只出現在一個組，我們無從知道「同一個人在另一組會如何」。想拆開？必須讓每個人都跑過所有條件——那就是第十八章的重複量數設計。
§3

親手拆解：每個人的分數怎麼組裝出來

用第七章的心像實驗（M·· = 7、M1· = 4、M2· = 10）。點選任一位受試者，看他的分數如何由三個零件組成。

🧩 分數模型的組裝過程：從總平均出發，加上效果、加上誤差，得到觀察值（點選受試者）
受試者Yas=M··+est αa+est es(a)
✅ 兩個可以自我檢查的性質
① 每一組的 est αa 加總 × 各組人數 = 0：5×(−3) + 5×(+3) = 0 ✓
② 每一組內部的 est es(a) 加總 = 0：控制組 (−3−2+1+2+2) = 0 ✓、實驗組 (−2−2−1+1+4) = 0 ✓
（這正是課本 (10.15) 式要你驗證的練習。）
🔗 分數模型與平方和的連結

把分數模型代進平方和的定義，會得到兩個關鍵結果：

SSA = S · Σ(est αa)²　　← 效果 + 誤差
SSS(A) = ΣΣ(est es(a))²　　← 只有誤差

組內平方和「純粹只由誤差項組成」——這句話終於從直覺變成了數學事實。而組間平方和則同時包含了效果與誤差。這正是 F 比值設計的理論根據。

§4

樣本 vs 母體：兩套符號別搞混

統計學的核心永遠是：用手上的樣本，去猜背後的母體。所以每個概念都有兩個符號——一個給樣本、一個給母體。

概念母體參數（未知，用希臘字母）樣本統計量（算得出來，用拉丁字母）
總平均μ··（mu dot dot）M·· = 7
第 a 組平均μa·（mu a dot）Ma·
第 a 組的處理效果αa = μa· − μ··est αa = Ma· − M··
誤差es(a)est es(a) = Yas − Ma·
誤差變異數σ²eMSS(A)
⚠️ 一個微妙但重要的區別：模型假設誤差在母體中的平均是 0（E{e} = 0），但在樣本裡，估計出來的 est e 每組加總剛好是 0——那是因為我們用該組平均去減的緣故，是算術的必然，不是抽樣的巧合。
兩者長得像，意義完全不同。這種區別正是自由度會「少掉」的原因。
§5

期望均方（EMS）：本章最重要的兩行

如果我把同一個實驗重複無限多次，每次算出的 MSA 與 MSS(A) 平均起來會是多少？這個「長期平均值」叫做期望值（expected value），寫作 E{ }。

從分數模型出發，可以推導出（推導過程在課本附錄 F）：

期望均方 Expected Mean Squares · 課本 (10.22) 式
E{MSA} = σ²e + S·θ²a

E{MSS(A)} = σ²e
其中 θ²a = Σα²a ／ (A − 1)（讀作 theta squared a），代表自變數效果的強度。
這兩行把第七章的直覺「F = (效果+誤差)/誤差」變成了嚴格的數學敘述。

🎯 終於證明了：為什麼 H₀ 下 F ≈ 1

當 H₀ 為真時，所有 αa = 0（沒有任何組被推高或壓低）→ Σα²a = 0 → θ²a = 0。代入 EMS：

E{MSA} = σ²e + S×0 = σ²e
E{MSS(A)} = σ²e
兩者的期望值完全相同！

既然分子分母都在估計同一個 σ²e，它們的比值自然會在 1 附近徘徊。而且因為兩個估計來自不同的平方和（第七章證明過：交叉項 = 0 ⟹ 互相獨立），數學上可以證明：兩個獨立、估計同一變異數的比值，服從 Fisher F 分配。

第八章那句「若 H₀ 為真，F 服從 F 分配」的來源，就在這裡。分數模型是整個推論的地基。

📌 順便看懂 S 的角色：EMS 中效果項是 S × θ²a——人數 S 是效果的放大器。這正好呼應第八章 (8.9) 式的「放大係數」。同一件事，從兩個方向被推導出來。
§6

細節控角落：為什麼是 θ²a 而不是 σ²a？

這一節課本自己標為「digression（岔題）」，但它決定了 ω² 公式長什麼樣，值得花三分鐘。

問題出在除以 A 還是除以 A − 1：

σ²a　＝　Σα²a ／ A

  • 叫做「A 的變異數」
  • 除以 A：因為固定因子的 A 個水準就是全部的水準——它們構成完整的母體，不是抽樣
  • 算有限母體的變異數，除以元素個數

θ²a　＝　Σα²a ／ (A − 1)

  • 叫做「A 的均方成分」
  • 除以 A − 1：因為它是從 MSA 的期望值推導出來的（MS 本來就要除以 df = A − 1）
  • 出現在 EMS 公式裡
兩者的換算關係
σ²a = [(A − 1) ／ A] · θ²a　　⟺　　θ²a = [A ／ (A − 1)] · σ²a
差別有多大？當 A = 2 時，θ²a 是 σ²a 的兩倍——差一倍不是小事！
A 越大差距越小（A = 10 時只差 11%），但在心理學常見的 2–4 組實驗中，混用會造成明顯偏誤。
🎯 為什麼要斤斤計較？因為效果量 ω² 的定義用的是 σ²a（真正的變異數），而我們從資料能估到的是 θ²a（EMS 裡的成分）。§9 的 ω² 公式中那個看起來很怪的 (A − 1) 因子，就是這個轉換留下的痕跡。
§7

固定因子 vs 隨機因子（Model I 與 Model II）

到目前為止我們都假設自變數是固定因子。這個假設值得攤開來講，因為它決定了你的結論能推論到多遠。

🔒 固定因子（Model I）

  • 實驗中出現的水準就是你關心的全部水準
  • 別人複製你的實驗時，會用完全相同的水準
  • 你關心的是每一個水準各自的效果（αa 的大小）
  • 例子：有心像 vs 無心像；四種脈絡條件；藥物 vs 安慰劑
  • EMS：E{MSA} = σ²e + S·θ²a
  • 效果量用 ω²

🎲 隨機因子（Model II）

  • 實驗中的水準是從一個更大的母體隨機抽出來的
  • 別人複製時會抽到不同的水準
  • 你關心的是整個因子的總體影響，不是特定水準
  • 例子：隨機抽 5 張人臉當刺激；隨機抽 20 個單字；隨機抽 8 所學校
  • EMS：E{MSA} = σ²e + S·σ²a
  • 效果量用 ρ²
🧮 好消息：在 S(A) 設計中，計算完全一樣！
SS、df、MS、F、臨界值——全部相同，ANOVA 表長得一模一樣。差別純粹在方法論的詮釋與效果量的選擇。

⚠️ 但到了多因子設計（第十六章之後），固定 / 隨機的區別會直接改變 F 的分母該用誰——那時就不再只是詮釋問題了。
🤔 怎麼判斷自己的因子是哪一種？問這一句

「如果別人要複製我的研究，他會用一模一樣的水準嗎？」

・會（有心像 vs 無心像，不可能改）→ 固定因子
・不會（他會另外隨機抽 5 張臉）→ 隨機因子

心理學研究中，絕大多數單因子設計都是固定因子。但「刺激材料」（單字、圖片、臉孔）其實常常應該當成隨機因子——這正是近年語言與認知心理學強調「把材料當隨機效果」（混合效果模型）的原因。用錯了，會嚴重低估標準誤、膨脹型 I 錯誤。

§8

當 F 小於 1：草莓籃的寓言

如果 MSA < MSS(A)，F 就會小於 1。表面上看「離顯著更遠了」，沒什麼好談。但 F 明顯小於 1 其實是個警訊——它可能表示你的模型有問題。

畢竟按照 EMS，H₀ 為真時 F 應該在 1 附近；F 遠小於 1 意味著組平均彼此「太像了」，像到不像是隨機分派能造成的。

🍓 草莓農夫與他的籃子

從前有位農夫要把草莓拿去市場賣。他剛讀完《隨機化的樂趣》，決定用隨機分派把草莓裝進 100 個籃子——每顆草莓都查一次亂數表決定去哪一籃。

結果呢？有些籃子裝滿了又大又漂亮的草莓，有些籃子普普通通，有些籃子淨是可憐的小草莓。市場上的客人當然搶購漂亮的籃子，沒人要那些寒酸的籃子。農夫的爛草莓全部滯銷。

下次去市場前，農夫學乖了——他不再隨機分派，而是刻意「均質化」：每一籃都精心搭配，讓所有籃子看起來一樣好（其實是太過一樣了）。這次全部賣光。

因為熱愛統計，農夫還跑了一次 ANOVA：以草莓為受試者、重量為依變數、籃子為隨機因子 𝒜。他得到 F < 1，於是滿意地確認：自己的均質化非常成功。

🍓

成因一：均質化（草莓籃效應）

某個因素讓各組平均過度相似。通常是分派過程不夠隨機（例如刻意配對、實驗者暗中平衡各組）。

診斷方向：檢查你的隨機分派程序是不是真的隨機。

👻

成因二：被忽略的隱藏變數

課本的例子：你雇了兩位實驗者，一位魅力四射、一位死氣沉沉，而且兩人都跑了兩種條件。「實驗者」這個變數被丟進了誤差項，把 MSS(A) 灌得虛胖，F 因此被壓下去。

解法：把它納入模型當一個因子，或改善控制（例如訓練實驗者一致化）。

🔢 想檢定「F 是否真的顯著小於 1」？利用 F 分配的一個漂亮性質：

F(ν₁, ν₂) 小於某值的機率　＝　1/F 在 F(ν₂, ν₁) 下大於該倒數的機率（注意兩個自由度對調）

課本示範：想找 ν₁ = 5、ν₂ = 20、α = .05 的左尾臨界值 → 改查 ν₁ = 20、ν₂ = 5 的右尾臨界值 = 4.56 → 取倒數：1／4.56 = .22。
所以若你的 F < .22，就可以拒絕「兩個變異數相等」的假設，正式宣告有草莓籃效應。
💡 一個更廣的教訓：課本在這裡順帶提醒——誤差項被不當膨脹，也可能讓真實存在的效果變得不顯著。所以「沒有顯著」永遠不等於「沒有效果」，它也可能只是「你忘了控制某個變數」。這是「不可接受 H₀」的另一個理由。
§9

不偏的效果量：ω² 與 ρ²

終於來到本章的實用產出。第八章的 R² 只描述「手上這批樣本」，會系統性高估母體效果。現在有了 EMS，我們可以反推母體的變異數成分，做出推論統計版本的效果量。

母體定義：效果變異佔總變異的比例
固定因子：ω²A·Y = σ²a ／ (σ²e + σ²a)　　隨機因子：ρ²A·Y = σ²a ／ (σ²e + σ²a)
兩條式子長得一樣，但 σ²a 的意義不同（固定因子的 σ²a = Σα²a/A；隨機因子的 σ²a = E{a²a}），所以估計公式也不同。

推導：怎麼從 MS 反推出 σ²a？

1

兩式相減，把 σ²e 消掉

MSA − MSS(A) = (σ²e + S·θ²a) − σ²e = S · est θ²a

2

除以 S，得到 θ²a 的估計

est θ²a = (MSA − MSS(A)) ／ S

3

用 §6 的換算轉成 σ²a

est σ²a = [(A−1)／A] × est θ²a = (A−1)(MSA − MSS(A)) ／ (A·S)

💡 看到了嗎？§6 那個「除以 A 還是 A−1」的糾結，就是在這裡派上用場。

4

代入定義並化簡

ω² 的計算公式 · 課本 (10.27) 式
ω̂²A·Y = [SSA − (A − 1)·MSS(A)] ／ [SStotal + MSS(A)]
分子被扣掉了 (A−1)·MSS(A)——那正是「即使沒有效果，光靠誤差也會產生的那部分 SSA」。這就是修正高估的機制。

實例：Romeo and Juliet

A = 4、S = 5、SSA = 50.95、SSS(A) = 37.60、SStotal = 88.55、MSS(A) = 2.35：

代入計算
ω̂² = [50.95 − 3 × 2.35] ／ [88.55 + 2.35] = 43.90 ／ 90.90 = .48
對照第八章算過的 R² = 50.95／88.55 = .575。

R² 說「解釋了 57.5% 的變異」，ω² 說「其實只有 48.3%」——R² 高估了約 9 個百分點。

隨機因子版本：ρ²

ρ² 的計算公式 · 課本 (10.28) 式
ρ̂²A·Y = (MSA − MSS(A)) ／ [MSA + (S − 1)·MSS(A)]
課本範例：A = 5、S = 9、MSA = 87.00、MSS(A) = 9.00
ρ̂² = (87.00 − 9.00) ／ [87.00 + 8 × 9.00] = 78.00 ／ 159.00 = .49

注意這裡不需要 (A−1)/A 的轉換——因為隨機因子的 σ²a 本來就是變異數，不必再換算。
➖ 如果算出負數怎麼辦？當 MSA < MSS(A)（也就是 F < 1）時，ω̂² 和 ρ̂² 會變成負值。但變異數的比例不可能是負的，所以慣例是直接回報 0。
順帶一提：算出負值本身就是個提示——回去看 §8，你可能遇上草莓籃效應或漏掉了某個變數。
🧪 效果量要不要檢定？不用另外做。「效果量為 0」這個虛無假設，跟 ANOVA 的「各組平均相等」完全是同一個假設——所以標準的 F 檢定同時檢定了兩者。
§10

三個效果量，實務上該用哪一個？

指標屬於回答的問題什麼時候用
R²Y·A / η²描述統計「這批樣本裡，自變數解釋了多少變異？」好算好懂、能連結迴歸觀點（第九章）、任何設計都算得出來。最常被使用。
ω²推論統計「母體中，固定因子解釋了多少變異？」要估計母體效果、要做統合分析、樣本小的時候。
ρ²推論統計「母體中，隨機因子解釋了多少變異？」自變數的水準是隨機抽出來的時候。
📏

大小關係是固定的

R² > ω²　（永遠成立）

課本直言：R² 比較受歡迎，可能也跟它總是給出比較漂亮的數字有關。（誠實得可愛。）

📉

df > 80 之後就沒差了

當總自由度超過 80，三個指標的數值會非常接近（Fowler, 1985）。這時選哪個只是品味問題。

反過來說：小樣本時務必報 ω²。

🤨

一個哲學上的警告

課本引多位學者指出：對固定因子而言，「效果量」的意義其實很可疑——因為你隨時可以靠改善實驗控制（降低 σ²e）把效果量做大。

所以固定因子的效果量，反映的往往是實驗做得多乾淨，而不只是效果本身多強。

📝 寫論文時的實用建議：
① 一律報告 R²（或 η²、偏 η²），因為讀者最熟悉、也最容易跟其他研究比較；
② 樣本不大（df < 80）時，同時報告 ω²，展現你知道 R² 有偏誤；
③ 跨研究比較效果量時要小心：兩個研究的誤差控制程度不同，效果量就不能直接比。
§K
